# 交替课程（Alternating Courses）

## 关键判断：数据层零改动

现有校验器 R13（`ScheduleValidator.kt:137-155`）的规则是「同一天 span 相交 **且** 周数相交 ⇒ 冲突」。也就是说，**同一格的课程只要周数不重合就已合法**，`WeekPattern` 的 `Parity.ODD/EVEN` 早就算得准。所以几门课共用一格 = 交替课程，天然不需要新字段：

- 不加 groupId、不加时间戳、不动 `SCHEDULE_FORMAT_VERSION` 与 `ScheduleStore` 的版本闸门、不写迁移。
- 「首先添加的那门」= `Schedule.courses` 列表顺序（`upsertCourse` 对新课走 `courses + withId` 追加，编辑按 id 原位替换，顺序稳定）。
- 需求 5「周数不能重合」已由 R13 强制（同一起始节 ⇒ span 必然相交 ⇒ 周数必须互斥），无需新增规则。


## 2. 渲染解析：一格只画一张卡

数据层查询不动，解析放在 UI 纯函数里。

`ui/schedule/ScheduleModels.kt`：`Course` 增一个字段

```kotlin
/** 非本周交替课的配色 → 卡片底部 1/4 色条；null = 该格没有交替课（或本卡已置灰） */
val alternateBar: CourseColor? = null,
```

并新增纯函数（与 `findAt` 同文件、同风格）：

```kotlin
/**
 * 每个格子只保留本周要画的那张卡：组里本周上课的那门优先，全组本周都不上则退回列表
 * 首项（照旧置灰）；非当周的组员不画卡，只把**非本周里最先添加的那门**的配色记到
 * primary.alternateBar 上。保持原列表顺序。
 */
fun List<Course>.resolveWeekCards(): List<Course>
```

`ui/schedule/ScheduleAdapters.kt` 加两个入口，共用上面这套解析：

```kotlin
internal fun List<CourseOccurrence>.toWeekCards(showInactive: Boolean): List<Course>  // 仓库路径
internal fun List<CourseEntry>.toWeekCards(week: Int): List<Course>                    // 编辑态草稿路径
```

`ScheduleScreen` 两条路径换用它们（`ScheduleScreen.kt:206-223` 与 `:241-264`）。**注意仓库路径要先把全量课程（`coursesForWeek`，不是 `visibleCoursesForWeek`）映射出来再解析**，否则「显示本周不上的课」关闭时，本周那张卡上的交替色条会一起消失；过滤条件改成解析之后再按 `it.active` 剔除（语义与现在完全一致）。

顺带修掉一个既有缺口：`findAt` 的 firstOrNull 语义保持不变，但喂进去的列表已只剩每格一张卡，所以叠层跨节卡不会再盖住同格另一门课；`isContinuationAt` 也随之只认「本周真正在画的跨节卡」——当某周上课的是那门单节课时，它下面那格会正确地空出来（可点可加课）。

## 3. 卡片视觉：底部 1/4 色条

`ui/schedule/CourseCard.kt`：左侧 3dp 竖条从单个 Box 换成按 3:1 分段的 Column，比例对单节课卡与跨节卡（`requiredHeight` 撑出的整卡高度）都成立：

```kotlin
Column(Modifier.width(BarWidth).fillMaxHeight()) {
    Box(Modifier.fillMaxWidth().weight(3f).background(barColor))
    course.alternateBar?.let { Box(Modifier.fillMaxWidth().weight(1f).background(it.barColor)) }
}
```

- 只有当周卡（`active`）才画下段：整格本周都不上课时卡片照旧整体置灰，不掺彩色。
- 上段颜色、起止时间文字颜色、内容排版全部不变。
- 另加 `onLongClick: (() -> Unit)? = null` 参数：非空时把 `clickable` 换成 `combinedClickable`（编辑态才传）。加一个对应 `@Preview`（橙上绿下，对齐图一）。

## 4. 长按接线（`ui/schedule/CourseGrid.kt`）

- `CourseGrid` 新增参数 `onCourseLongClick: ((courseId: String, anchor: Rect) -> Unit)? = null`，透传到 `GridRow` 与叠加层的两处 `CourseCard`。
- 每张卡挂一个非 State 的坐标持有者，长按时把窗口坐标报上去（`onGloballyPositioned` 内写普通字段，不触发重组）：

```kotlin
/** 卡片窗口坐标（长按弹菜单用）：只在按下时读，非 State，避免布局阶段触发重组 */
private class BoundsHolder { var value: Rect = Rect.Zero }
```

- 编辑态才传回调（普通态长按无反应，与普通态点击无反应一致）。
- 跨节卡长按区域待上机确认：卡片节点自带手势，溢出到下一节那部分能否命中由 Compose 命中测试决定；若不能，就在叠加层给该格加同样的 `requiredHeight`，让命中区覆盖整卡。

## 7. 面板改造（`ui/schedule/AddCoursePanel.kt`）

新增两个参数：

```kotlin
existing: CourseEntry? = null,
alternateFrom: CourseEntry? = null,       // 非空 = 以某课为基准新建交替课（与 existing 互斥）
blockedWeeks: Set<Int> = emptySet(),      // 组内其它课占用的周：方格灰显不可点
```

- **新建交替课**：标题「新建交替课程」；星期/起始节由调用方传源课的；结束节次锁定（`EndSlotChips` 加 `enabledRange: IntRange` 参数，只放行源课那一个末节）；周数默认 = `1..totalWeeks` 减去占用周（父课单周 → 新课默认双周）；配色默认 = 组内没用过的第一个（避免上下同色看不出来）；姓名/教师/地点为空并照旧自动聚焦。
- **编辑已有课**（含交替课成员）：`blockedWeeks` = 组内**其它**课的周；被占周在方格里用现有禁用样式（`OnPrimaryContainer.copy(alpha = 0.4f)`）灰显且点不动。
- 「全选/单周/双周」快捷：先按快捷取周再去掉占用周；结果为空则不改选择并给出新错误文案。
- 方格下方加占用提示行（复用同文件已有的 `weeksSummary`）：每门其它课一行「「X」已占用：第 1-15 周（单周）」。
- `submit()` 里追加一道占用周检查（防进程重建后恢复出越界选择），给出比通用冲突更清楚的文案；R13 仍作为最后兜底。

## 8. 屏幕接线（`ui/schedule/ScheduleScreen.kt`）

新增三个状态。菜单与选择弹窗都是瞬时 UI，用普通 `remember`（不 `rememberSaveable`，Rect 不可存）——旋转即收起，可接受：

- `menuTarget: (courseId, Rect)?` → 渲染 `CourseContextMenu`；选「新建交替课程」→ `alternateSourceId = courseId` 并收起菜单。
- `chooserSourceId: String` → 点击已有课卡时：若该卡所在组 `cellCourses(...)` 成员 ≥ 2，开选择弹窗；只有一门则照旧直开编辑面板。选中某门 → `editTargetId = 该课 id`，关弹窗。
- `alternateSourceId: String` → 以源课开 `AddCoursePanel(alternateFrom = 源课, blockedWeeks = 占用周)`，确认走 `editSession.add(entry)`（与现有新增路径同一出口，`addedCourses()` → `upsertCourse`，保存链路无需改动）。
