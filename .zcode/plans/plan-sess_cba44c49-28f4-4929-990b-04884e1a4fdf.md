## 目标

进入/退出编辑态时，三处硬切改为同步过渡动画（网格保持瞬切）：

| 元素 | 进入编辑 | 退出编辑 |
|---|---|---|
| 编辑栏 `ScheduleEditBar` | 从顶部滑入 + 淡入 | 向上滑出 + 淡出 |
| 原顶栏 `ScheduleHeader` | 向上滑出 + 淡出 | 从顶部滑回 + 淡入 |
| 底部导航栏 | 下移出屏 + 淡出 | 上移入屏 + 淡入 |

统一规格：`tween(350ms, FastOutSlowInEasing)`，两处动画同一帧启动（都由同一个 `editing` 翻转驱动），天然严格同步。风格与项目既有约定一致（tween + 具名时长常量 + 中文注释说明意图）。

## 改动

### 1. `MainActivity.kt`
- 新增 `internal const val EditTransitionMillis = 350`（放在 `TabTransitionMillis` 旁边，注释说明调参方式；`internal` 供 `ScheduleScreen.kt` 共用，避免两处数值漂移）。
- 底部导航栏 `if (!editing) { BottomNavBar(...) }`（`MainActivity.kt:120`）改为 `AnimatedVisibility(visible = !editing)`：
  - `enter = slideInVertically(tween(EditTransitionMillis, easing = FastOutSlowInEasing)) { it } + fadeIn(tween(EditTransitionMillis))`——初始偏移为自身高度，即"上移入"；
  - `exit = slideOutVertically(...) { it } + fadeOut(...)`——滑向自身高度下方，即"下移出"；
  - `modifier = Modifier.align(Alignment.BottomCenter)` 保留。
- 防误触：过渡期间导航栏仍处于组合中，`onTabSelected` 改为 `{ if (!editing) selectedTab = it }`（保持原"编辑中不许切 tab"语义）。

### 2. `ScheduleScreen.kt`
- 顶栏 if/else 硬切（`ScheduleScreen.kt:374-408`）改为 `AnimatedContent`：
  - `targetState = editSession == null`，`contentAlignment = Alignment.TopStart`；
  - `transitionSpec` 进出对称：新内容 `slideInVertically(tween) { -it } + fadeIn(tween)`，旧内容 `slideOutVertically(tween) { -it } + fadeOut(tween)`，用 `togetherWith` 组合——进入编辑时编辑栏从上滑入、顶栏向上退出；退出时反向；
  - 内容 lambda **必须用参数**（`{ viewing -> if (viewing) ScheduleHeader(...) else ScheduleEditBar(...) }`）而非外层 `editSession`，这是 AnimatedContent 的标准坑；
  - 两栏的 `onGloballyPositioned` 实测高度采集原样保留（防首帧跳闪机制不动）。
- 网格 `contentPadding.top` 维持 `if (editing) editBarHeight else headerHeight` 瞬切（已确认）。
- 已核对的边界：退出时 `editSession` 立即变 `Inactive`，退场中的旧编辑栏其保存回调经 `onSaveEdit` 的 null 检查不会误写；进程重建恢复 `editing = true` 时 AnimatedContent 初始态不播动画、AnimatedVisibility 不组合，无异常表现。

### 涉及 import
`androidx.compose.animation.AnimatedContent / AnimatedVisibility / slideInVertically / slideOutVertically / fadeIn / fadeOut / togetherWith`、`androidx.compose.animation.core.FastOutSlowInEasing`（MainActivity 与 ScheduleScreen 各自补齐）。

## 验证
1. `gradlew compileDebugKotlin` 编译通过。
2. 动画观感需模拟器/真机确认（`gradlew installDebug` 或用户自测），检查点：
   - 点编辑按钮：编辑栏滑入、顶栏滑出、导航栏下移出，三者同步无错拍；
   - 保存 / 取消 / 系统返回键三种退出路径动画一致；
   - 动画中途快速连点编辑/取消，状态正确不崩；
   - 退出编辑时两层毛玻璃叠加约 150ms，若观感发闷，微调方案：fade 用短一半的时长（如 175ms），位移不变。

## 不做的事
- 网格（加号、日期带消失、顶部留白跳变）保持瞬切——已确认；
- `AddCoursePanel`、设置页等其它覆盖层不动。
