# 滑动联动动画顺序调整：恢复时日期带先于顶栏图标

## 需求（已与用户确认）

课表页滑动联动涉及三段动画：① 顶部编辑/设置图标渐隐 ② 周数胶囊移位 ③ 网格顶部日期数字带（DateBand，CourseGrid.kt:89）渐隐。

- **上滑折叠**：先 ① 图标渐隐 + ② 胶囊移位（56dp 折叠段），折叠满后列表才滚动、③ 日期带再渐隐（44dp 段）。**现状已符合，不改**。
- **下滑恢复**：先列表滚回顶部使 ③ 日期带恢复，继续下滑才展开顶栏、恢复 ① 图标与 ② 胶囊。**现状顺序相反（顶栏先恢复），本次要改的就是这里**。

## 现状根因

`CollapseState.kt:50-58` 的 `nestedScrollConnection`（经 ScheduleScreen.kt:76 挂在 CourseGrid 的 LazyColumn 上），`onPreScroll` 对**两个方向**都先手消费：

- 上滑（delta<0）→ 折叠：pre 先消费 ✓ 顺序正确
- 下滑（delta>0）→ 展开：pre 也先消费 → **顶栏先恢复，列表后回顶** ✗

## 方案（只改一个文件）

**文件**：`app/src/main/java/com/fangyi/classpp/ui/schedule/CollapseState.kt`

按方向拆分消费时机（Compose 嵌套滚动语义：同一 delta 的派发顺序为 parent `onPreScroll` → 子列表消费 → parent `onPostScroll` → overscroll）：

```kotlin
override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset =
    // 折叠先手：上滑在子列表消费前抢折叠；展开不在 pre 消费，让给下滑恢复顺序
    if (available.y < 0f) consumeDelta(available.y) else Offset.Zero

override fun onPostScroll(
    consumed: Offset,
    available: Offset,
    source: NestedScrollSource,
): Offset =
    // 展开后手：下滑先让子列表滚回顶部（DateBand 恢复），列表到顶后的剩余才用于展开
    if (available.y > 0f) consumeDelta(available.y) else Offset.Zero
```

（post 显式加 `> 0f` 方向判断，不依赖"负 delta 恒为 0"的隐式推理，防止日后改 pre 时踩坑。）

同时更新类头 KDoc（CollapseState.kt:20-28）的"消费规则"段：

> 上滑（delta<0）在 pre 阶段优先折叠，折叠满后子列表才滚动；下滑（delta>0）子列表先滚回顶部，列表到顶后的剩余在 post 阶段展开；fling 逐帧同走 pre/post，剩余速度 decay 收尾；clamp 越界自动停止。

### 不改的部分（已评审确认）

- `onPostFling` decay 惯性：下甩时子列表 fling 先走（到顶后剩余帧经 post、或剩余速度经 onPostFling decay 展开，两条路径互斥不双计）；上甩时 pre 逐帧先手折叠——两个方向顺序都天然正确。
- `consumeDelta` 主体、`menuOpen` 暂停、`dragEpoch` 防重入：原样保留。
- `ScheduleHeader.kt` / `CourseGrid.kt` / `ScheduleScreen.kt`：不动。

### 关键推导（设计评审已核实）

- 下滑拖动：pre 不动 → 列表滚动（`available>0` 只在列表到顶后出现在 post）→ post 展开 ⇒ 顺序正确。
- post 中的负 delta 恒为 0（pre 已把折叠消费到 clamp 边界），故 post 实际等效只处理展开；上滑行为与旧逻辑完全一致。
- 新逻辑下「折叠未满且列表已滚」的中间态手势不可达（展开只发生在列表到顶后），状态机自洽；overscroll 在 post 之后派发，不会抢展开。

## 验证

1. 编译：`.\gradlew.bat :app:compileDebugKotlin`。
2. 运行 app 手测：
   - **上滑拖动**（回归）：图标先隐 → 56dp 折叠满 → 列表才滚、日期带渐隐；胶囊先移到日期行右端；
   - **下滑拖动**（本次目标）：从「折叠 + 日期带已隐」慢慢下滑——列表先滚回顶、日期带先恢复，**然后**顶栏才展开、图标淡回；
   - **fling 双向**：上甩顺序不回归；下甩到顶后顶栏才展开，收尾无跳变；
   - **展开态直接下甩**：顶栏不动、列表正常、底部 overscroll 正常；
   - **折叠满 + 列表在顶**上滑：列表立即滚、日期带正常渐隐；
   - 周数下拉菜单打开时手势仍暂停（`menuOpen`）；fling 中途按下无 offset 跳变（`dragEpoch`）；
   - 快速上下变向、弱 fling、到底/到顶边界不回归。
3. Android Studio Preview：`ScheduleHeaderExpandedPreview` / `ScheduleHeaderCollapsedPreview` 正常。
