# 课表设置页 UI 改造（设计稿风格，可复用设置页模板）

Android 原生（Kotlin + Jetpack Compose + Material3，仅浅色主题，无 material-icons）。目标：按设计稿重设 `ui/settings/SettingsScreen.kt`，并把这套样式抽成后续设置详情页可复用的组件。

**已确认决策**：文案与日期格式全部按设计稿；基础组件抽到独立文件 `ui/settings/SettingsUi.kt`；弹窗（DatePicker / TimePicker / 周数输入）保持现状；既有功能行为（周数联动、`appendSlot` 加节、溢出禁用、ErrorBox、校验拒绝链）不变。

---

| 设计元素 | 实现 |
|---|---|
| 页面底色 | `Scaffold` 默认 `background = #F2F4F6`（已如此，不动） |

| 设置行 | 左标签（黑、SemiBold 16sp）+ 右值（`Primary`）+ 行尾 chevron（`ic_chevron_right`，`SecondaryTextColor`），整行可点 |
| 每周上课天数 | 卡内两选项：选中 = `PrimaryContainerNontrans #E0EDFD` 圆角块 + ✓（`ic_checkmark`）+ `Primary` 字；未选 = 透明底 + 黑字 |
| 节数与时间 | **两张卡**：卡 A「每天 N 节」+ 右侧「减一节」「加一节」蓝色文字按钮；卡 B 节次行（黑粗标签 + 两个时间 chip） |

### 1.5 `SettingRow(...)` — 通用设置行
```kotlin
/**
 * 通用设置行：左标签 + 右侧内容。
 * - [onClick] 非空 → 整行可点，行尾自动补 chevron（设置页模板行）
 * - [value] 非空 → 显示 Primary 色数值（如日期、周数）
 * - [trailing] 非空 → 右侧自定义槽（Switch、时间 chip、文字按钮等），与 value 并存时 trailing 在最右
 */
@Composable
internal fun SettingRow(
    label: String,
    modifier: Modifier = Modifier,
    onClick: (() -> Unit)? = null,
    value: String? = null,
    showChevron: Boolean = onClick != null,
    trailing: (@Composable () -> Unit)? = null,
) {
    Row(
        modifier = modifier
            .fillMaxWidth()
            .then(if (onClick != null) Modifier.clickable(onClick = onClick) else Modifier)
            .padding(vertical = 12.dp),
        verticalAlignment = Alignment.CenterVertically,
    ) {
        Text(
            text = label,
            modifier = Modifier.weight(1f),
            style = MaterialTheme.typography.bodyLarge,
            fontWeight = FontWeight.SemiBold,
            color = MaterialTheme.colorScheme.onSurface,
        )
        if (value != null) {
            Text(value, style = MaterialTheme.typography.bodyLarge, color = Primary)
        }
        trailing?.invoke()
        if (showChevron) {
            Spacer(Modifier.width(6.dp))
            Icon(
                painter = painterResource(R.drawable.ic_chevron_right),
                contentDescription = null,
                tint = SecondaryTextColor,
                modifier = Modifier.size(20.dp),
            )
        }
    }
}
```

### 1.7 `SegmentedChoice(options, selectedIndex, onSelect)` — 两选项分段控件
**自绘而非 M3 `SegmentedButton`**：设计稿是简单圆角块 + 勾选，不是 M3 的缺角分段外形；自绘可精确上 `PrimaryContainerNontrans`/`Primary`，也避免 M3 `itemColors` 各版本参数名差异。
```kotlin
@Composable
internal fun SegmentedChoice(
    options: List<String>,
    selectedIndex: Int,
    onSelect: (Int) -> Unit,
    modifier: Modifier = Modifier,
) {
    Row(modifier = modifier.fillMaxWidth()) {
        options.forEachIndexed { index, label ->
            val selected = index == selectedIndex
            Row(
                modifier = Modifier
                    .weight(1f)
                    .clip(SegmentShape)
                    .background(if (selected) PrimaryContainerNontrans else Color.Transparent)
                    .clickable { onSelect(index) }
                    .padding(vertical = 12.dp),
                horizontalArrangement = Arrangement.Center,
                verticalAlignment = Alignment.CenterVertically,
            ) {
                if (selected) {
                    Icon(
                        painter = painterResource(R.drawable.ic_checkmark),
                        contentDescription = null,
                        tint = Primary,
                        modifier = Modifier.size(18.dp),
                    )
                    Spacer(Modifier.width(6.dp))
                }
                Text(
                    text = label,
                    style = MaterialTheme.typography.bodyLarge,
                    color = if (selected) Primary else MaterialTheme.colorScheme.onSurface,
                )
            }
        }
    }
}
```

### 1.8 日期展示格式（设计稿 `2026-9-7`，无前导零）
```kotlin
/** 日期 → `2026-9-7`（无前导零），走 [R.string.date_hyphen_format] */
@Composable
internal fun IsoDate.toSettingsDateText(): String {
    val parts = toString().split('-')
    val year = parts.getOrNull(0)?.toIntOrNull() ?: 0
    val month = parts.getOrNull(1)?.toIntOrNull() ?: 0
    val day = parts.getOrNull(2)?.toIntOrNull() ?: 0
    return stringResource(R.string.date_hyphen_format, year, month, day)
}
```
（命名区别于 `ScheduleSwitcherSheet.kt:475` 的私有 `toDisplayText()` —— 那个走 `date_cn_format`「2026年3月2日」，本次不动。）

## 6. 风险与注意点

- **`Background` 与 `SurfaceContainer` 同值 `#F2F4F6`**：卡片必须用 `Surface` 白，否则与背景无色差。
- **`PrimaryContainerNontrans` / `SecondaryTextColor` 未进 colorScheme**：只能 `import com.fangyi.classpp.ui.theme.X` 直接引用。
- **`ic_arrow_left` / `ic_chevron_right` / `ic_checkmark` 首次被引用**：vector 的 `fillColor=#212121` 会被 `Icon(tint=...)` 覆盖，务必显式传 tint。
- **自绘分段控件**替代 M3 `SegmentedButton`：需自己处理两项等分、点击态（无 ripple 也可接受，或用 `clickable(indication = LocalIndication.current, interactionSource = remember { MutableInteractionSource() })` 保留水波纹）。
- **字符串同步**：`slot_decrease`/`slot_increase`/`date_hyphen_format` 两份 xml 都要有，`assembleDebug` 会暴露漏配。
- **无障碍**：返回按钮 `contentDescription = cd_settings_close`；chevron/勾选图标 `contentDescription = null`（装饰性）。
- **预览**：两个 `@Preview` 必须能编译；`SettingsUi` 组件不依赖 repository，可独立预览。
