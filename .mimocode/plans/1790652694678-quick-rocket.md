## 3. 数据层纯函数：追加节次

`app/src/main/java/com/fangyi/classpp/data/model/ScheduleModels.kt` — 在 `defaultSlotsFor`（L152-164）之后、`newUuid`（L166）之前插入。复用既有 `DEFAULT_BREAK_MINUTES = 30`（L11）；**`defaultSlotsFor` 保留不删**（3 个测试文件共 6 处 fixture 依赖它）。

```kotlin
/** 一天最后一分钟数（23:59）；追加节的结束不得越过 */
private const val LAST_MINUTE_OF_DAY = 1439

/** 追加节时长（分钟），与 [DEFAULT_SLOTS] 各节一致 */
private const val APPEND_SLOT_MINUTES = 100

/**
 * 保留现有 [slots] 并在末尾追加一节：新节开始 = 上一节结束 + [DEFAULT_BREAK_MINUTES]，
 * 时长 [APPEND_SLOT_MINUTES]。空表、末节时间文本非法、或新节结束晚于 23:59 时返回 null
 * （调用方据此禁用「＋」；节数上限 12 由调用方把控）。
 */
fun appendSlot(slots: List<TimeSlotDef>): List<TimeSlotDef>? {
    val lastEnd = slots.lastOrNull()?.let { TimeText.parseMinutes(it.endTime) } ?: return null
    val start = lastEnd + DEFAULT_BREAK_MINUTES
    val end = start + APPEND_SLOT_MINUTES
    if (end > LAST_MINUTE_OF_DAY) return null
    return slots + TimeSlotDef(TimeText.format(start), TimeText.format(end))
}
```

越界防护：`parseMinutes` 只返回 `0..1439` 或 null；`end > 1439` 先返回 null，故 `TimeText.format` 的 `require(0..1439)` 不可达。

关键数值：默认 5 节末节 `20:50`(1250) → 第 6 节 `21:20–23:00` ✓；第 7 节 `23:30–25:10` → null（UI 禁用「＋」）。

## 4. 周数 → 结束日推算（共享纯函数）

`app/src/main/java/com/fangyi/classpp/ui/schedule/TermDateSnap.kt` 文件末尾（L19 后）追加：

```kotlin
/** 学期周数选择允许范围（周数对话框的数字校验边界） */
const val TERM_WEEKS_MIN = 1
const val TERM_WEEKS_MAX = 30

/**
 * 保持开始日不变，把结束日换算到 [weeks] 整周：结束日只整周平移，
 * 星期几不变（周五仍周五、周日仍周日），整周边界天然保持。
 */
fun endForTotalWeeks(start: IsoDate, end: IsoDate, weeks: Int): IsoDate {
    val currentWeeks = ((end - start).toInt() / 7) + 1   // 与 Schedule.totalWeeks 同式
    return end + (weeks - currentWeeks) * 7
}
```

整周平移 ⇒ R1（开始周一）、R2/R2b（结束周五/周日）、R3（整周边界）构造上恒过，不需要新的校验分支。

**三向联动的现状确认（无需额外改动）**：
- 改开始日 → `SettingsScreen.kt:445-448` 已把结束日等量平移（delta 是 7 的倍数）⇒ **周数不变** ✓
- 改结束日 → `:450` 保持开始日，`totalWeeks` 是派生属性 ⇒ **周数自动变** ✓
- 选周数 → 新增入口（下面 §5）推算结束日 ⇒ **开始日不变** ✓

## 5. `TermDatesCard`：新增「学期总周数」行 + 对话框

`ui/settings/SettingsScreen.kt:511-531` 整体替换（`DateRow` / `SectionCard` 不动）：

```kotlin
/** 学期起止 + 总周数三行（起止弹 DatePicker、周数弹输入对话框），单独成组件供创建表单复用 */
@Composable
private fun TermDatesCard(
    start: IsoDate,
    end: IsoDate,
    onPickStart: () -> Unit,
    onPickEnd: () -> Unit,
    onSetWeeks: (weeks: Int) -> Unit,
) {
    // 与 Schedule.totalWeeks 同式；起止经吸附/校验保证整周边界，此值必为整数周
    val totalWeeks = ((end - start).toInt() / 7) + 1
    var pickingWeeks by remember { mutableStateOf(false) }

    SectionCard(title = stringResource(R.string.section_term)) {
        DateRow(stringResource(R.string.term_start), start.toString(), onPickStart)
        Spacer(Modifier.height(8.dp))
        DateRow(stringResource(R.string.term_end), end.toString(), onPickEnd)
        Spacer(Modifier.height(8.dp))
        DateRow(
            label = stringResource(R.string.term_weeks),
            value = stringResource(R.string.term_weeks_value, totalWeeks),
            onClick = { pickingWeeks = true },
        )
    }

    // 周数对话框：仅打开期间进入组合（关闭即出组合，重开以当前周数重置输入）；
    // 非法输入（空/0/>30）→ 字段 isError + 确定禁用；取消/外部点击丢弃
    if (pickingWeeks) {
        var input by remember { mutableStateOf(totalWeeks.toString()) }
        val weeks = input.toIntOrNull()?.takeIf { it in TERM_WEEKS_MIN..TERM_WEEKS_MAX }
        AlertDialog(
            onDismissRequest = { pickingWeeks = false },
            title = { Text(stringResource(R.string.term_weeks)) },
            text = {
                OutlinedTextField(
                    value = input,
                    // 只留 ASCII 数字并截 2 位（1..30 至多两位），结构性杜绝 "-5"/"abc"/全角数字
                    onValueChange = { input = it.filter { c -> c in '0'..'9' }.take(2) },
                    singleLine = true,
                    keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Number),
                    isError = weeks == null,
                    supportingText = { Text(stringResource(R.string.term_weeks_range)) },
                    modifier = Modifier.fillMaxWidth(),
                )
            },
            confirmButton = {
                TextButton(
                    enabled = weeks != null,
                    onClick = { weeks?.let(onSetWeeks); pickingWeeks = false },
                ) { Text(stringResource(R.string.settings_confirm)) }
            },
            dismissButton = {
                TextButton(onClick = { pickingWeeks = false }) {
                    Text(stringResource(R.string.settings_cancel))
                }
            },
        )
    }
}
```

（`DateRow` 是位置参数 `(label, value, onClick)`，照现有签名写。）

- `SettingsContent`（`SettingsScreen.kt:304-309`）— 走仓库 `setTerm`，课程越界由既有 `rejection()` → `ErrorBox` 拒绝，`error = null` + `submit` 已在 `:147-150` 的 `onTerm` 包装里：

## 10. 风险与注意点

- **字符串重命名原子性**：`slot_reset_desc` → `slot_append_desc` 必须同时改两个 xml + `SettingsScreen.kt:370`，`assembleDebug` 可暴露。
- **`defaultSlotsFor` 不能删**：改后主源码零调用，但测试 6 处 fixture 依赖（Kotlin 不报未使用的 public 顶层函数）。
- **周 pager 自动联动**：`ScheduleScreen.kt:129/132/209/547` 全读 `schedule.totalWeeks`，缩周时选中周经 `coerceIn` 自动回钳，与既有 `setTerm` 行为一致，无需新代码。
- **对话框放在 Card 外**：`TermDatesCard` 会 emit `SectionCard` + `AlertDialog` 两个节点；`AlertDialog` 是独立窗口，不受外层 `verticalScroll` Column 裁剪。
- **过滤用 `c in '0'..'9'` 而非 `isDigit()`**：避免全角数字混入 `toIntOrNull`。
- **课程越界拒绝链复用**：`setTerm` → `rejection()` → `CoursesOutOfRange` → 既有 `ErrorBox`/`toMessage`，不新增错误处理。
