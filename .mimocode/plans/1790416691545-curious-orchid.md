# 课表网格线条实现计划

## 需求（已与用户确认）

根据设计图为课表网格绘制线条，颜色统一使用 Color.kt 中的 `Outline`（`0xFFDCE2E7`，Color.kt:40，已通过 Theme.kt:33 接入 theme 但全工程尚未被引用）：

1. **4 条竖线**：位于 `width*i/5`（i=1..4），与 5 列对齐；从**日期带顶部一直贯穿到最后一行底部**（竖线穿过日期带区域）。
2. **日期带顶部 1 条横线**：作为星期行（一~五）与网格的分隔线，随日期带一起滚动渐隐。
3. **日期带与第一行课程之间没有横线**。
4. **节次行之间有横线**（即每个 GridRow 底部一条）。

## 方案

只改一个文件：`app/src/main/java/com/fangyi/classpp/ui/schedule/CourseGrid.kt`。项目中此前没有任何 Canvas/drawBehind/Divider 代码，这是第一处绘制。

用 `Modifier.drawBehind` 分别加在两个已有 composable 上（`drawBehind` 绘制在子内容之下，不透明的 CourseCard 会盖住线，线条只出现在 8.dp 沟槽与空单元格中——竖线恰好落在两侧 4.dp CellPadding 的中间，行底线落在行底部 4.dp padding 内，不会压到卡片）。

### 1. GridRow（CourseGrid.kt:124-127）

在 `Row` 的 modifier 链 `.height(GridRowHeight)` 之后追加 `.drawBehind { ... }`：

- 循环 `i in 1..4` 画 4 条竖线，`x = (size.width * i / 5f).roundToInt().toFloat()`（列宽是整数 px，取整保证清晰），从 `0f` 到 `size.height`。
- 画底部横线：`y = size.height - stroke/2`，从 `0f` 到 `size.width`（内缩半个笔画避免被裁掉一半）。
- 每行都画底行 ⇒ 行间横线自然产生，最后一行在 8.dp spacer 上方收尾。

不画顶部横线 ⇒ 满足"日期带与第一行之间无横线"。

### 2. DateBand（CourseGrid.kt:87-99）

在 modifier 链**末尾**（`.background(surfaceContainer)` 之后）追加 `.drawBehind { ... }`：

- 同样 4 条竖线（贯穿日期带高度，与下行 GridRow 的竖线首尾相接连续）。
- 顶部横线：`y = stroke/2`。不画底部横线。

**modifier 顺序关键**：`… → .graphicsLayer{alpha渐隐} → .background(…) → .drawBehind{…}`。
- drawBehind 必须在 graphicsLayer **之后**（更内层），线条才会随日期带渐隐动画一起淡出；
- drawBehind 必须在 background **之后**，线条才会画在带底色之上。

### 公共细节

- 笔宽：`1.dp.toPx()`（DrawScope 自带 Density receiver）。
- 颜色：直接 import `com.fangyi.classpp.ui.theme.Outline`（原始 val，可在非组合的 draw lambda 中直接用；用户明确要求用 Color.kt 里的 Outline）。
- 新增 imports：`androidx.compose.ui.geometry.Offset`、`com.fangyi.classpp.ui.theme.Outline`。

### 不改的文件

- `ScheduleHeader.kt`：星期行下方的分隔线由 DateBand 顶部横线承担，头部不动。
- `Color.kt` / `Theme.kt`：Outline 已就绪。
- 其余文件均不涉及。

## 验证

1. **Preview**：Android Studio 中查看 `CourseGridPreview`（CourseGrid.kt:149），确认 4 条竖线贯穿日期带到底、日期带顶部有横线、日期带与首行卡片之间无横线、行间有横线，且卡片上无线条遮挡。
2. **滚动**：运行 app 或 Preview 滚动课表——日期带渐隐时其顶部横线与竖线段一起淡出，下方 GridRow 竖线无缝衔接。
3. **对齐**：竖线与头部星期行（ScheduleHeader.kt:153-168，同为零边距五等分）的列边界对齐。
4. 构建无报错（`:app:compileDebugKotlin` 或 IDE 编译）。
