# 课表页 · 内容区左右滑动翻周（跟手动画）

## 需求与已定方案

在课表**内容区**左右滑动 → 切换上一周 / 下一周；上一周、本周、下一周的**课程卡片与网格线跟手横移**；**顶栏完全不动**。

用户已选定两点：

1. 顶栏周数胶囊与日期标题在**拖动过半时**即切换（跟手），而非松手落位后；
2. 边界（第 1 周右滑 / 末周左滑）沿用 **Pager 系统默认拉伸反馈**，不写自定义回弹。

## 核心结构：Pager 放在 LazyColumn 的唯一 item 里

每周一页，但**纵向滚动留在 Pager 之外**——这是本方案的关键取舍：

- 若把整个网格塞进 Pager 的每页（每页各持一个 LazyColumn），拖动途中相邻周会停在自己的纵向滚动位置，与当前周错位，"跟手"当场露馅；
- 因此每页 = 「日期带 + 各节次行 + 尾部留白」，不含纵向滚动；外层仍是**一个 LazyColumn**（`state` / `contentPadding` / 折叠 nestedScroll / hazeSource 全部原样），只滚这一整个 Pager；
- 于是三页永远共享同一纵向位置与折叠状态，顶栏作为叠层里的独立一层纹丝不动；
- 副产品：日期带渐隐与 `blurProgress` 无需改动——Pager 恒为唯一可视 item，`firstVisibleItemIndex == 0` 守卫语义不变，`firstVisibleItemScrollOffset` 仍是"内容上滚量"，两处公式逐帧等价。

不新增依赖：`HorizontalPager` 在 `androidx.compose.foundation` 内，项目已在该 artifact 上（`LazyColumn`/`background`），编译类路径本就具备。

## 改动清单

### 1. `ui/schedule/ScheduleModels.kt`

新增 `WeekPageContent(week, courses, dates, highlightDate)`：一周的整页渲染数据，按页周号现取（翻到哪页取哪周，无需预算相邻周）。

### 2. `ui/schedule/CourseGrid.kt`

签名改为 `CourseGrid(pagerState, timeSlots, contentForWeek: (Int) -> WeekPageContent, modifier, state, contentPadding)`。

- LazyColumn 内容 → 单个 `item(key = "weekPager")`：
  - `Modifier.fillMaxWidth().height(pageHeight)`，`pageHeight = DateBandHeight + GridRowHeight * timeSlots.size + TrailingScrollSpace`（显式高度，避开 item 纵向约束无界）；
  - `beyondViewportPageCount = 1` 预组合邻页，手势第一帧就有内容；
  - `flingBehavior = PagerDefaults.flingBehavior(state, pagerSnapDistance = PagerSnapDistance.atMost(1))`：一次手势最多翻一周。
- 新增 `WeekPage`：`Column { DateBand; timeSlots.forEach { GridRow }; Spacer(TrailingScrollSpace) }`；`DateBand` / `GridRow` 内部绘制逻辑未改。
- **接缝线**：静止时页右缘与屏幕右缘重合无需补；翻页/拖动途中它正是相邻周分界，不补会让分界处两列并成一宽列。故按 `PagerState.isSeamVisible`（`currentPageOffsetFraction != 0f`，draw 阶段读取，不触发重组）补右缘竖线，**分两段**：
  - 课程行区由页级 `drawBehind` 补（行内无底色，画在身后即可），上起日期带下缘、下止最后一个节次行（不含尾部留白）；
  - 日期带区由 `DateBand` 自己的 `drawBehind` 补——页级那条会被日期带的底色盖住；画在带内 ⇒ 与带内其它竖线一同渐隐，滚过顶栏后不会留一截浮线。
  - 两段同 x（`size.width - stroke/2`）同笔宽，接成一条完整的列分界线。

### 3. `ui/schedule/ScheduleScreen.kt`

- `activeSchedule.collectAsState()` 拆成 `scheduleState` + `schedule`：Pager 的 `pageCount` 闭包在创建时被捕获，读 State 才不会被过期的 `Schedule` 实例钉死（学期起止改长后 20 → 25 周仍能翻到）。
- 删掉顶层 `courses` / `weekDates`，改由 `contentForWeek`（`remember(schedule, currentWeek, today)`，纯内存读）供页取用；`timeSlots` 加 `remember(schedule)` 稳定实例，减少翻页期重组。
- 在 `schedule != null` 分支内：

```kotlin
val pagerState = rememberPagerState(initialPage = week - 1) {
    scheduleState.value?.totalWeeks ?: 1
}
val contentForWeek: (Int) -> WeekPageContent = remember(schedule, currentWeek, today) { { pageWeek -> ... } }

// 手势 → 周次：currentPage 拖动过半即翻转 → 顶栏周数/日期随之切换
LaunchedEffect(pagerState) {
    snapshotFlow { pagerState.currentPage }.collect { selectedWeek = it + 1 }
}
// 周次 → 翻页：弹窗/返回本周/钳制；相邻周动画，跨多周直接落位
LaunchedEffect(week) {
    val target = week - 1; val current = pagerState.currentPage
    if (current != target) {
        if (abs(current - target) == 1) pagerState.animateScrollToPage(target)
        else pagerState.scrollToPage(target)
    }
}
```

- 两者不互踢：手势写回后 `LaunchedEffect(week)` 重启即 `current == target` 直接返回；弹窗跳周的动画途中 `currentPage` 翻转写回的是同一个值（State 同值写入被忽略）。
- 初始页 = 目标周（Pager 只在有课表时创建），无首帧跳变；选择周后顶栏日期与页内高亮同规则（本周 = 今天，其它周 = 该周周一）。

## 帧率（补充：上机发现掉帧后的处理）

与 tab 平移同源：页面没有自己的图层时，绘制指令录在最近的那一层里，只要页面位置逐帧变化，
那一层就得逐帧把整页指令重录。这里治两处：

1. **每个周页各加一层**：`WeekPage` 根节点挂 `Modifier.graphicsLayer { }`。周 Pager 靠 placement 移动
   页面，有图层后每帧只更新"这一层画在哪"，页面内容（日期带 + 各行卡片）的指令表保持缓存。
2. **接缝竖线的开关改为派生布尔 state**：`CourseGrid` 里 `derivedStateOf { pagerState.isSeamVisible }`，
   页与日期带在 draw 中读该 state。若在 draw 里直接读 `currentPageOffsetFraction`，拖动中它逐帧都变，
   会让页面图层逐帧失效、整页指令重录——第 1 条优化会被这一处抵消。派生 state 只在起手/落位翻转一次，
   既不重组也不逐帧重录。

（tab 平移的同类处理见 `1790556084759-silent-comet.md`：位移拆成"布局槽位 + layer 追赶"。）

## 待上机确认（回退路径已备）

1. **拖动过半顶栏是否即时切换**：若本版本 `PagerState.currentPage` 实际只在落位时更新，则退化为"停稳后更新"；此时改用 `currentPageOffsetFraction` 推导预测周号（一处改动）。
2. **接缝线**：拖动途中相邻周分界应有竖线、两列不被并成一宽列，且竖线穿过日期带（日期带那一段随日期带一同渐隐）；静止时屏幕右缘不应出现多余边线。
3. **一次手势一周**：甩动不跨周跳（`atMost(1)`）；若观感想跨多周，去掉 `pagerSnapDistance` 即可。
4. **边界**：第 1 周右滑 / 末周左滑为系统拉伸反馈；若要硬停，给 Pager 传 `overscrollEffect = null`。
5. **纵向不回归**：上滑折叠 + 日期带渐隐 + 模糊渐入；下滑先列表到顶、再恢复日期带与顶栏的既有顺序不变；滚动范围与改动前一致。
6. **三页共享滚动**：滚到中段再左右拖动，相邻周与当前周处于同一纵向位置。
7. **帧率**：慢动作看拖动与落位是否均匀；需要量化时——
