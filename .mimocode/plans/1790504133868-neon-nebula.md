# 课表数据↔UI 对接 + 设置页 实现计划

## 需求与已确认范围（用户拍板）

批任务两件事：**①课表数据层接入现有 UI**（吃掉 mock 数据）；**②设置页**，与课表顶栏右侧设置按钮联动。

接入点规范 = `.mimocode/plans/1790501046221-happy-rocket.md` 文末《后续 UI 接入路径》（用户确认即"计划 §12"）：
适配层 `CourseEntry→ui.Course` / `CourseColor` 同名 valueOf / `TimeSlotDef→TimeSlot` / `schedule.slots` 替代 `DefaultTimeSlots`；`ScheduleScreen` 改从 `activeSchedule` + `visibleCoursesForWeek` 取数。

| 决策点 | 拍板结果 |
|---|---|
| 视图能力 | **仅换数据源**：网格保持 5 列硬编码单格渲染；span>1 只渲染起始格；7 天视图（列/星期行）后续批次 |
| 设置页范围 | **当前课表全套设置**：学期起止、每周天数 5/7、节数+各节时间、置灰开关；带结构化拒绝错误提示。课表管理（切换/重命名/删除）、分享、编辑按钮联动 → 后续批次 |
| 首装空状态 | **不播种**：课表页空状态 + 设置页内"新建课表"表单；创建入口仅在 `activeSchedule==null` 时出现 |
| 置灰 | `showInactiveCourses=true` 时非活跃课：卡片底 `#cbcbcb`、课名 `#737a83`（需求 7 原文） |

- DatePicker `selectedDateMillis` = UTC 零点毫秒 ↔ `epochDay * 86_400_000L` 直转，免时区坑。
- 项目规则：中文注释；字符串中英双份；屏幕 `ui/<feature>/XxxScreen.kt`；state 纯 Compose 本地态。

## 总体架构与状态流

```
MainActivity
  ├─ rememberScheduleRepository(): ScheduleRepository?   ← remember+LaunchedEffect 调 suspend get(appContext)
  ├─ var showSettings by rememberSaveable                ← 设置页开关
  ├─ ScheduleScreen(modifier, repository, onOpenSettings) ← 常驻组合、不重建
  ├─ BottomNavBar
  └─ if (showSettings) SettingsScreen(onClose, repository) ← 最后组合，全屏覆盖（含底栏）

读：repository.activeSchedule.collectAsState() → Schedule?
    → ScheduleScreen 内 remember(schedule, week) 调 visibleCoursesForWeek / datesForWeek(take 5) / schedule.slots
    → 任何 mutator 成功 → publish → activeSchedule 新实例 → 记忆键失效 → 三路数据同帧刷新
写：SettingsScreen rememberCoroutineScope.launch { repo.setXxx(...) }
    → Ok 清错误；Err → 内联错误框（ScheduleError→中文文案）
```

- 仓库获取只在 MainActivity 做一次，以参数下传两屏（单一获取点、同实例、默认参 `= null` 保 Preview 编译；不用 CompositionLocal——项目零此惯例）。
- `get()` 返回即加载完成 ⇒ 无中间脏态；repo null 仅首帧毫秒级。

## 适配层（新建 `ui/schedule/ScheduleAdapters.kt`，internal，中文 KDoc）

```kotlin
// span>1 本批只渲染起始格 ⇒ slotId = startSlot；active 置灰标志随行
internal fun CourseOccurrence.toUiCourse(): Course = Course(
    name = course.name, teacher = course.teacher, location = course.location,
    dayOfWeek = course.dayOfWeek, slotId = course.startSlot,
    color = CourseColor.valueOf(course.color.name), active = active,
)
// 节次列表位置即 id（1-based），与 CourseGrid items(key = it.id) 一致
internal fun List<TimeSlotDef>.toUiSlots(): List<TimeSlot> =
    mapIndexed { i, d -> TimeSlot(i + 1, d.startTime, d.endTime) }
// IsoDate → Date：按 toString() 拆 y/m/d → 本地 Calendar 正午 12:00（isSameDay/dayOfMonth 抗时区/夏令时）
internal fun IsoDate.toUiDate(): Date
// DatePicker 专用互转（UTC 零点毫秒语义）
internal fun IsoDate.toPickerMillis(): Long = epochDay * 86_400_000L
internal fun Long.toIsoDate(): IsoDate = IsoDate(Math.floorDiv(this, 86_400_000L))
```

## 设置页（新建 `ui/settings/SettingsScreen.kt`）

```kotlin
@OptIn(ExperimentalMaterial3Api::class)
fun SettingsScreen(onClose: () -> Unit, modifier: Modifier = Modifier,
                   repository: ScheduleRepository? = null)
```

**骨架**：`Scaffold(topBar = TopAppBar(设置, navigationIcon = 关闭 IconButton→onClose))` + LazyColumn；文件内 `BackHandler`；`repository==null` → 居中指示器；`activeSchedule==null` → **仅新建表单区**；否则 **仅设置区**（创建入口自动消失 = "仅无激活课表可创建"，避免 create 不切活产生到不了的课表）。各分区为 private @Composable（数据 + 回调 lambda 入参，shell 持 repository/scope/error），底部 2 个 @Preview（用手工构造的 `Schedule(id="preview", termStart=IsoDate.parse("2026-03-02"), …)` 与空表单，不依赖 repo）。

**分区与交互**（逐项即时应用：`scope.launch { … }`，Ok→清错误 / Err→错误框）：

1. **学期**：`TermDateRow`（只读 OutlinedTextField：学期开始/学期结束）→ 点击弹 `DatePickerDialog`（`rememberDatePickerState(initialSelectedDateMillis = iso.toPickerMillis())`）。**自动吸附**（裁定：周一起始/周五(日)结束是校验硬规则，用户无从知晓，吸附消除大部分摩擦；错误框仅兜底）：开始→所选日所在周周一；结束→days=5 吸附周五、days=7 吸附周日 → `setTerm(id, start, end)`。
2. **每周天数**：5/7 二选一（SegmentedButton；若 API 实验性不稳则退 FilterChip/OutlinedButton Row，编译定夺）→ `setDaysPerWeek`。days=7 而 termEnd=周五 → `Err(TermEndInvalid)`，**错误文案走 `error_term_end_days7` 专项**（shell 知当前 days 可区分）："7 天模式下学期结束必须是周日，请先调整学期结束"。
3. **节数与时间**：`slot_count_format` + `－/＋` 步进 1..12，附 `slot_reset_desc` 说明。**裁定 R3：变更即整表 `defaultSlotsFor(n)` 重生成**（前缀保留/裁剪可能撞已自定义时间产生 SlotOrderInvalid；重生成构造上必过校验、行为可预测，与数据层启发式一致；提示文案覆盖"已自定义时间会被重置"）。每节一行 `第N节 8:00 – 9:40`，点起/止时间分别弹 **Material3 `TimePicker` + AlertDialog**（选 TimePicker 而非文本框：结构性杜绝格式错误、免键盘遮挡；确认 → `TimeText.format(h*60+m)` → 全表 `setSlots`）。
4. **显示**：`Switch` ← `showInactiveCourses` → `setShowInactiveCourses`（恒 Ok）。
5. **新建课表**（仅空态）：名称 OutlinedTextField + 学期起止（同上吸附；默认 开始=今天所在周周一、结束=开始+15 周的周五，即 16 周）+ 创建按钮 → `createSchedule`；Ok → `onClose()` 回课表页；名称空白由仓库校验报 `InvalidScheduleName`。

**错误机制**：内联错误框（裁定，不用 Snackbar——项目零基建）：内容区顶部 `Surface(color = MaterialTheme.colorScheme.errorContainer)` + Text；新操作成功即清。

`ScheduleError → 文案` 映射（@Composable，覆盖设置页可达全集）：
`TermNotMonday→error_term_not_monday`、`TermEndInvalid→error_term_end`/`error_term_end_days7`、`TermRangeInvalid→error_term_range`、`DaysPerWeekInvalid→error_days_per_week`、`SlotCountInvalid→error_slot_count`、`SlotTimeFormatInvalid→error_slot_time_format`、`SlotOrderInvalid→error_slot_order`、`InvalidScheduleName→error_schedule_name`、`CoursesOutOfRange→error_courses_out_of_range`（%1$d=affected.size、%2$s=affected 前 3 门课名 join）、`NotFound→error_not_found`、`PersistFailed→error_persist_failed`、其余→`error_generic`（CourseField/WeeksBeyond/GridConflict 经 rejection() 必归并为 CoursesOutOfRange，已闭合）。

## 边界情况

- 学期缩短/增长 → `week` 自动钳制 `1..totalWeeks`；越界查询 repo 返回 [] 亦无害（双保险）。
- daysPerWeek=7 → dates take(5)、网格/星期行不动、day6/7 课程天然不可见（findAt 不查）。
- span>1 → 适配层落 startSlot，续格 findAt 无匹配自然留空（已核 CourseGrid.kt:188）。
- 调节数/切天数/改学期成功 → activeSchedule 新实例 → courses/weekDates/timeSlots 同帧刷新；LazyColumn `key=slot.id` 正确 diff。
- 旋转/强杀重启：selectedWeek、showSettings rememberSaveable；repo 单例重载 activeScheduleId。
- 损坏恢复（loadState≠Ready）→ 一次性 Toast（`load_state_restored` / `load_state_reset`）。
- **R1（已裁定）**：本批无课程编辑 UI，网格是否有课只能靠种子数据验收 → 手动测试用附录种子 JSON（`adb push`），课程逻辑本身已由数据层 8 个单测覆盖，不为验收加产品代码。
