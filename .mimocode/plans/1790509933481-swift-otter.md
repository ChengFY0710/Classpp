# 课表页 · 周数弹窗「本周」高亮

## 需求

周数选择弹窗的方块三态：

| 状态 | 背景 | 文字 |
|---|---|---|
| 选中周（== selectedWeek） | `colorScheme.primary` 蓝底 | 白字 Bold（现状，不变） |
| **本周**（当前系统周，且未被选中） | `colorScheme.primaryContainer` 浅蓝底 | `colorScheme.primary` 蓝字 |
| 其它 | `colorScheme.surfaceVariant` | `colorScheme.onSurfaceVariant`（现状，不变） |

> 日期层联动经用户确认已正常，本次不做。
> 本周与选中重合时选中态优先（即正常蓝底白字）。

## 现状关键点

- 「本周」来源：`ScheduleScreen.kt:86-90` 已用 `repository.termPosition(schedule.id)`——`TermPosition.InTerm.week` 即当前周；`BeforeTerm`/`AfterTerm` 无本周概念 → 不高亮。
- 配色：`ui/theme/Color.kt` `PrimaryContainer = 0x1F006FEF`、`Primary = 0xFF006FEF`，已在 `Theme.kt` 映射进 `colorScheme`，直接用 `MaterialTheme.colorScheme.primaryContainer / primary`。
- 传参链：`ScheduleHeader → WeekPill → WeekPickerCardSurface → WeekPickerCard → WeekCell`。

## 修改（2 个文件）

### 1. `app/src/main/java/com/fangyi/classpp/ui/schedule/ScheduleScreen.kt`

- 计算当前周（`schedule` 非空时，纯函数、可 remember）：
  ```kotlin
  val currentWeek: Int? = if (schedule != null) {
      remember(schedule) {
          (repository.termPosition(schedule.id) as? TermPosition.InTerm)?.week
      }
  } else {
      null
  }
  ```
- `ScheduleHeader(...)` 调用处新增 `currentWeek = currentWeek`。

### 2. `app/src/main/java/com/fangyi/classpp/ui/schedule/ScheduleHeader.kt`

- `ScheduleHeader` 签名加 `currentWeek: Int? = null`（默认值保持现有 @Preview 兼容），透传给 `WeekPill`；`WeekPill` → `WeekPickerCardSurface` → `WeekPickerCard` 同样加 `currentWeek: Int? = null` 参数逐层下传。
- `WeekCell` 加参数 `isCurrent: Boolean = false`，配色改为三态 `when`：
  ```kotlin
  val (background, foreground) = when {
      selected -> colors.primary to Color.White
      isCurrent -> colors.primaryContainer to colors.primary
      else -> colors.surfaceVariant to colors.onSurfaceVariant
  }
  ```
  （`WeekPickerCard` 里传 `isCurrent = week == currentWeek`；selected 分支在前天然保证优先级。）
- 文字字重维持现状：选中 Bold、其余 Medium。

## 验证

1. `.\gradlew.bat :app:compileDebugKotlin`（项目根 `E:\VibeCoding\Classpp`）。
2. 手动清单：
   - 学期内打开弹窗：当前周方块浅蓝底蓝字（当选中的是别的周）；
   - 选中「本周」自身：变蓝底白字；
   - 选中其它周后，本周方块恢复浅蓝底蓝字；
   - 学期前/学期后（或 `currentWeek` 无法取到）：无浅蓝方块，仅蓝底白字选中态。
