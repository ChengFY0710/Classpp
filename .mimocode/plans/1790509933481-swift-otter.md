# 课表页 · 周数弹窗展开/收起动画（M3 官方同款）

## 需求与已定方案

弹窗展开与消失加动画。**用户已选定：Material3 DropdownMenu 官方同款——缩放 + 淡入淡出，锚定胶囊方向展开。**

M3 `Menu.kt`（material3-1.4.0 源码已核实）的官方参数：

- scale：`ClosedScaleTarget = 0.8f` → `ExpandedScaleTarget = 1f`，用 FastSpatial 曲线；
- alpha：`0f → 1f`，用 FastEffects 曲线（比缩放快，先出内容再定型）；
- `transformOrigin` 由锚点/菜单包围盒计算，缩放朝锚点方向发生；
- 生命周期用 `MutableTransitionState`：`if (currentState || targetState)` 保持组合存在，收起动画播完才真正离开组合。

## 实现（仅 `app/src/main/java/com/fangyi/classpp/ui/schedule/ScheduleHeader.kt`）

改 `WeekPill` 中的弹窗组装（现为 `if (menuExpanded) { Popup(...) { WeekPickerCardShell(...) } }`）：

```kotlin
val expandedState = remember { MutableTransitionState(false) }
expandedState.targetState = menuExpanded

// targetState=true（展开中/已展开）或 currentState=true（收起动画未播完）都保持 Popup 在场
if (expandedState.currentState || expandedState.targetState) {
    Popup(
        onDismissRequest = { closeMenu() },
        popupPositionProvider = positionProvider,
        properties = PopupProperties(focusable = true),
    ) {
        val transition = updateTransition(expandedState, label = "WeekPicker")
        val scale by transition.animateFloat(
            transitionSpec = { tween(200, easing = FastOutSlowInEasing) },
        ) { expanded -> if (expanded) 1f else 0.8f }
        val alpha by transition.animateFloat(
            transitionSpec = { tween(120, easing = FastOutSlowInEasing) },
        ) { expanded -> if (expanded) 1f else 0f }

        WeekPickerCardShell(
            selectedWeek = selectedWeek,
            currentWeek = currentWeek,
            weekRange = weekRange,
            hazeState = hazeState,
            // 传入 modifier 链最外层：整体缩放/淡入包住裁剪、投影与毛玻璃
            modifier = Modifier.graphicsLayer {
                scaleX = scale
                scaleY = scale
                this.alpha = alpha
                // 顶部中心≈胶囊所在位置，向胶囊方向展开（折叠态胶囊偏右，保持顶部中心为简化）
                transformOrigin = TransformOrigin(0.5f, 0f)
            },
            onWeekSelected = { onWeekSelected(it); closeMenu() },
        )
    }
}
```

要点：

1. **组合生命周期**：去掉 `if (menuExpanded)`，改用 `MutableTransitionState` 守卫——点外部/返回键/选周触发 `closeMenu()` 后 `targetState=false`，收起动画播完 `currentState=false` 才移除 Popup；动画期间再点胶囊可反向重新展开。
2. **动画作用层**：`WeekPickerCardShell` 已有 `modifier` 参数，把动画 `graphicsLayer` 传进去会排在其内部 padding/裁剪/投影/毛玻璃**之外**——整卡（含阴影）一起缩放淡入，不破坏圆角裁剪与 haze。
3. **曲线取值**：M3 fast 效果约 200ms/100ms 量级；这里显式 `tween` 缩放 200ms、透明度 120ms（比缩放略快），避免依赖 `MotionSchemeKeyTokens` 的额外 API 面。
4. 定位（屏幕居中 + 胶囊下固定间距）、外部点击收起、返回键收起、`menuOpen` 复位逻辑均不变；`closeMenu()` 仍在收起开始时复位（折叠手势在淡出期间即恢复，可接受）。
5. 新增 import：`MutableTransitionState`、`updateTransition`、`animateFloat`、`tween`、`FastOutSlowInEasing`、`TransformOrigin`（`graphicsLayer` 已有）。

## 验证

1. `.\gradlew.bat :app:compileDebugKotlin`。
2. 手动：点胶囊 → 卡片从 0.8 缩放 + 淡入（约 200ms，顶部中心为锚）；点外部/返回键/选中某周 → 反向淡出收起；快速连点胶囊 → 展开/收起可中断反向；动画期间定位与阴影、毛玻璃效果不破。
