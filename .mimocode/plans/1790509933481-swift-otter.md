# 课表页 · 「返回本周」按钮

## 需求（对照设计图）

- 位置：顶栏日期行（`3月10日 周一`）**右侧**，图标 `ic_arrow_circle_left` + 蓝字「返回本周」，右对齐。
- 仅在**非本周**（`selectedWeek != currentWeek`，且学期中 `currentWeek != null`）显示。
- 点按 → 立即回到本周（复用现有选周链路，日期行/星期高亮/网格日期带自动联动恢复）。
- 上滑折叠时与编辑/设置图标**同款渐隐**（同一 `iconAlpha`），并同样在 `fraction ≥ 0.5` 后不可点。
- 图标资源已就位：`app/src/main/res/drawable/ic_arrow_circle_left.xml`（已确认存在）。

## 关键现状

- `ScheduleHeader.kt` 日期行是 `Layout` 的第 2 个子节点（约 :194-205）：单个 `Text`，`fillMaxWidth` + `padding(start = HeaderEdgePadding, top/bottom = 12)`。
- 折叠渐隐已有现成变量：`iconAlpha = 1f - fraction`、`iconsEnabled = fraction < 0.5f`（:119-121），编辑/设置图标正是用它们。
- `ScheduleHeader` 已持有 `selectedWeek`（即当前查看周）与 `currentWeek`（上一功能加入），点按回调可直接复用 `onWeekSelected(currentWeek)` —— **无需改 ScheduleScreen**。
- 日期行高度影响 `dateCenterY`（周数胶囊折叠锚点），按钮高度必须 ≤ 现有日期文字行高，避免头部布局位移。

## 修改（3 个文件）

### 1. `app/src/main/res/values/strings.xml` 与 `values-en/strings.xml`

在 `date_title_format` 后各加一行：

```xml
<!-- values -->
<string name="back_to_current_week">返回本周</string>
<!-- values-en -->
<string name="back_to_current_week">Back to this week</string>
```

### 2. `app/src/main/java/com/fangyi/classpp/ui/schedule/ScheduleHeader.kt`

**a. 日期行改为 Row（`Layout` 子节点 2，测量代码不动）**

```kotlin
Row(
    modifier = Modifier
        .fillMaxWidth()
        .padding(start = HeaderEdgePadding, top = 12.dp, bottom = 12.dp, end = 16.dp),
    verticalAlignment = Alignment.CenterVertically,
) {
    Text(dateTitle, fontSize = 23.sp, SemiBold, onSurface, letterSpacing = -0.3.sp) // 原样左对齐，去掉 fillMaxWidth
    Spacer(Modifier.weight(1f))
    if (showBackToCurrent) {
        BackToCurrentButton(
            onClick = { currentWeek?.let(onWeekSelected) },
            enabled = iconsEnabled,
            alpha = iconAlpha,
        )
    }
}
```

其中 `val showBackToCurrent = currentWeek != null && selectedWeek != currentWeek`（在 `ScheduleHeader` 内计算）。

- Row 高度 = max(日期文字 ~34dp, 按钮 ~32dp) ≈ 不变 → `dateCenterY`、胶囊折叠锚点、headerHeight 均不受影响。
- `Spacer(weight=1f)` 把按钮推到最右；`end = 16.dp` 为右侧留白（可调）。

**b. 新增私有组件 `BackToCurrentButton`**

```kotlin
@Composable
private fun BackToCurrentButton(
    onClick: () -> Unit,
    enabled: Boolean,
    alpha: Float,
    modifier: Modifier = Modifier,
) {
    Row(
        modifier = modifier
            .graphicsLayer { this.alpha = this@graphicsLayer.alpha ... 用参数 alpha }
            .clickable(enabled = enabled, onClick = onClick)
            .padding(horizontal = 4.dp, vertical = 4.dp),   // 扩大热区但不增 Row 高
        verticalAlignment = Alignment.CenterVertically,
    ) {
        Icon(painterResource(R.drawable.ic_arrow_circle_left), null, tint = colorScheme.primary, size = 24.dp)
        Spacer(Modifier.width(6.dp))
        Text(stringResource(R.string.back_to_current_week), 17.sp, SemiBold, colorScheme.primary)
    }
}
```

- 颜色统一 `colorScheme.primary`（与星期高亮/选中格同蓝）。
- `alpha`/`enabled` 直接吃编辑/设置图标同款 `iconAlpha`/`iconsEnabled` → 折叠时同步渐隐、半折叠后禁点。
- 热区 padding 只有 4dp，按钮总高 ≤ 日期文字高度，避免日期行变高。
- `ic_arrow_circle_left` 用 `Icon(tint = primary)` 上色（矢量自带 fill 会被 tint 覆盖）。

**c. 类 KDoc（可选）**：日期行描述补一句「右侧按需附带返回本周按钮」。

### 3. 无需改动

- `ScheduleScreen.kt`：回调复用 `onWeekSelected`；`currentWeek` 已传入。
- `@Preview`：`currentWeek` 默认 `null` → 按钮隐藏，预览不变。

## 验证

1. `.\gradlew.bat :app:compileDebugKotlin`。
2. 手动清单（学期内）：
   - 查看非本周：日期行右侧出现蓝色「← 返回本周」；点按 → 顶栏日期/星期高亮/网格日期带/周数胶囊全部回到本周，按钮消失；
   - 查看本周：按钮不出现；学期前/学期后：不出现；
   - 上滑折叠：按钮与编辑/设置图标同步渐隐；半折叠（≥0.5）后不可点，展开恢复；
   - 折叠态胶囊仍正常（锚点未因日期行变化而偏移）。
