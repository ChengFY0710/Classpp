# Classpp 课表网格阶段实现计划

## 背景与已确认取舍

- 项目：原生 Android（Kotlin + Compose + Material3），纯 Compose 本地状态，无 ViewModel/数据库。
- 顶部应用栏（`ScheduleHeader`）与折叠（`CollapseState`）已完成；内容区是占位 LazyColumn。
- 用户确认的取舍：
  1. **精简数据结构先行**：只做渲染所需字段 + mock 数据，持久化/编辑/weeks 规律后续再做。
  2. **固定节次行**：行 = 节次（8:00-9:40 等），不按真实时间比例。
  3. **单周 mock 数据**：选周时课表暂时显示同一份。
  4. **日期数字带**：作为网格第一行（灰色背景，9 10 11 12 13，今天高亮），**随 selectedWeek 动态计算**（需学期起始日常量），上滑滚动时**渐隐消失**。

## 关键现状（已核对代码）

- `ScheduleScreen.kt:42` `selectedWeek`（rememberSaveable）、`:70-75` `PlaceholderCourseList` 挂 `nestedScroll(collapseState.nestedScrollConnection)` —— 本阶段唯二接线点。
- `ScheduleHeader.kt:153-168` 星期行是 `Row.fillMaxWidth()` + `weight(1f)` 五等分、**零水平边距**（`HeaderEdgePadding=33.dp` 只作用于日期行）。网格列同样零水平边距五等分即可天然对齐，**无需共享 padding 常量**。
- 主题色在 `ui/theme/Color.kt`（`SurfaceContainer*`、`BrandBlue` 等），空单元格背景复用主题 surface 色阶。

## 1. 数据模型（`ScheduleModels.kt`）

```kotlin
/** 卡片渲染最小字段；持久化与 weeks 规律后续阶段再加 */
data class Course(
    val name: String,
    val teacher: String,
    val building: String,   // 如 "学武楼"
    val room: String,       // 如 "C201"
    val dayOfWeek: Int,     // 1..5（周一..周五）
    val slotId: Int,        // 所属节次（本阶段不支持跨节次）
    val color: CourseColor,
)

data class TimeSlot(val id: Int, val startTime: String, val endTime: String)

enum class CourseColor { Blue, Green, Yellow, Orange, Purple, Teal, Pink }

/** 学期第一个教学周一（2026-03-02，第1周 = 3月2日~3月6日） */
val TermStart: LocalDate = LocalDate.of(2026, 3, 2)

/** 5 节：与截图一致 */
val DefaultTimeSlots = listOf(
    TimeSlot(1, "8:00", "9:40"),
    TimeSlot(2, "10:10", "11:50"),
    TimeSlot(3, "14:30", "16:10"),
    TimeSlot(4, "16:40", "18:20"),
    TimeSlot(5, "19:10", "20:50"),
)

val MockCourses: List<Course> = listOf(/* 约 15 门，覆盖截图内容（微积分/电路原理/概率统计…） */)
```

- 颜色用**枚举**而非直接存 `Color`：模型零 Compose 依赖；`CourseColor → Color` 映射放 `CourseCard.kt` 私有扩展。
- 时间用字符串：卡片直接显示，本阶段不做时间轴计算。
- minSdk 24 < 26，`LocalDate` 需 `coreLibraryDesugaring` —— **检查 `app/build.gradle.kts`**：若未开启则改用 `java.util.Calendar` 计算周日期（避免新增构建配置）。

## 2. 网格 UI 架构（`CourseGrid.kt`）

**方案：`LazyColumn` + 每节次一个 `Row`（5 个 `Box(weight(1f))`）**。
- 与 header 星期行同款 `weight(1f)` 五等分、零水平边距 → 列天然对齐。
- 行高按节次固定（每格约 150dp 高，卡片填满行高留 4dp 间隙）。
- 不用 `LazyVerticalGrid`：行高按行取齐麻烦、25 格无 lazy 收益；不用 Canvas：文字排版/无障碍成本高。

```kotlin
@Composable
fun CourseGrid(
    courses: List<Course>,
    timeSlots: List<TimeSlot>,
    weekDates: List<Date>,   // 5 天日期，用于日期带
    today: Date,
    modifier: Modifier = Modifier,
)
```

结构（自上而下）：
1. **`DateBand`**（第一行）：5 列各显示日号（9/10/11…），今天 `primary` 高亮、其余 `onSurface`，灰色背景带。
   - 日期计算：`TermStart + (selectedWeek-1)*7天 + 0..4`，在 Screen 层算好传入 `weekDates`。
   - **渐隐**：`LazyColumn` 取 `firstVisibleItemScrollOffset`，`alpha = (1 - offset / bandHeight).coerceIn(0f, 1f)`，用 `graphicsLayer` 应用。
2. 各节次 `GridRow`：`Row.fillMaxWidth`，5 个 `CourseCell(weight(1f))`；cell 有课程渲染 `CourseCard`（外留 4dp 间隙形成网格沟槽），无课程铺空背景。

**折叠接入**：与现状完全一致，仅换组件——
```kotlin
CourseGrid(
    courses, timeSlots, weekDates, today,
    modifier = Modifier.weight(1f).fillMaxWidth()
        .nestedScroll(collapseState.nestedScrollConnection),
)
```

## 3. 课程卡片（`CourseCard.kt`）

```kotlin
@Composable
fun CourseCard(course: Course, slot: TimeSlot, modifier: Modifier = Modifier)
```

布局：白色底 12dp 圆角 `Box` > `Row`：
- 左侧 4dp 宽、满高竖条（`CourseColor` 映射色，`clip(RoundedCornerShape(topStart/bottomStart))`）；
- `Column(SpaceBetween)`：
  - 顶部 `slot.startTime`（竖条同色，10sp）；
  - 课程名（`SemiBold` 13sp，`maxLines=2`，ellipsis）；
  - `course.teacher`（灰 10sp，单行 ellipsis）；
  - `"@building room"`（灰 10sp，单行 ellipsis，走字符串资源）；
  - 底部 `slot.endTime`（竖条同色，10sp）。

颜色映射（私有，参考截图）：Pink `#F8B4C4`、Green `#7BC96F`、Yellow `#E6B848`、Orange `#F0955A`、Blue `#7FB3E8`、Purple `#B79BE0`、Teal `#5EC5B5`（实现时可微调）。

## 4. 数据流（`ScheduleScreen.kt`）

```kotlin
var selectedWeek by rememberSaveable { mutableIntStateOf(2) }
val courses = remember { MockCourses }
val timeSlots = remember { DefaultTimeSlots }
val weekDates = remember(selectedWeek) { /* TermStart 推算 5 天 */ }
```
- `selectedWeek` → `weekDates` → `DateBand`（课表本身本阶段不随周变，留 TODO 注释）。
- 后续接真实数据源：只需把 `remember { MockCourses }` 换成 ViewModel/Flow，`CourseGrid(List<Course>)` 签名不变。

## 6. 实施步骤（每步可独立验证）

1. **`ScheduleModels.kt`**：数据类 + 节次 + mock 数据 + `TermStart`；先查 `build.gradle.kts` 是否有 desugaring 决定 `LocalDate` 或 `Calendar`。编译通过。
2. **`CourseCard.kt`** + @Preview（覆盖：两行长课程名、晚课 19:10、窄文本溢出）。
3. **`CourseGrid.kt`**：`DateBand` + `GridRow` + 接入；@Preview 验证五列与静态对齐、空格背景、今天高亮、日期随周推算。
4. **接线 `ScheduleScreen.kt`**：删 `PlaceholderCourseList`，传入数据与 `nestedScroll`。
5. **资源与收尾**：en 翻译；运行 app 验证。

## 7. 验证方式

- `@Preview`：CourseCard（长名/晚课）、CourseGrid（展开内容 + 空 cell）、ScheduleScreen 整屏。
- 运行 app（模拟器/真机）检查：
  - 五列与 header 星期行**零边距对齐**、今天列高亮一致；
  - 上滑折叠跟手、fling 惯性（CollapseState 行为不回归）；
  - 日期带随选周 1..20 切换变化、今天高亮、上滑渐隐；
  - 窄屏（~360dp）卡片文字不溢出、课程名两行截断正常。

## 8. 边界与明确不做

- **不做**：跨节次课程（单 `slotId`）、同格冲突（mock 保证唯一，渲染取 `firstOrNull`）、持久化、weeks 规律、卡片点击详情、午休分隔行。
- 增删节次 = 改 `DefaultTimeSlots`（行自动增减）。
- 单元格冲突/重叠的渲染兜底：`firstOrNull` 取第一门。
