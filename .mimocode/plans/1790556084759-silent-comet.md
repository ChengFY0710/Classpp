# 底部导航切 tab · 内容平移切换

## 需求与已定方案

点按底部导航栏 → 三页内容横向平移切换（旧页滑出、新页滑入），导航栏与设置页覆盖层都不动。

用户已选定：

1. **连续平移**：三页像一条连续带子一起平移，跨两个 tab（日程 ⇄ 待办）时中间的课表页会快速扫过；
2. **300ms + FastOutSlowInEasing**（Material shared axis 同量级）；
3. **仅点按触发**，不加 tab 间滑动手势——既避免与课表「内容区左右滑动翻周」抢手势，也免掉外层可滚动容器的嵌套。

## 实现（仅 `MainActivity.kt`）

`offscreenWhenHidden`（把非选中页硬放到 `width * 2`）→ `tabPage`：偏移改为按序号差的动态值，动画就自然成立。

```kotlin
// tab 平移进度（浮点序号）：只在各页 measure 阶段被读取，整段动画每帧只重排、不重组
val tabProgress = animateFloatAsState(
    targetValue = selectedTab.ordinal.toFloat(),
    animationSpec = tween(TabTransitionMillis, easing = FastOutSlowInEasing),
    label = "tabProgress",
)

private const val TabTransitionMillis = 300

private fun Modifier.tabPage(tab: AppTab, progress: State<Float>, selected: Boolean): Modifier {
    val placed = this.layout { measurable, constraints ->
        val placeable = measurable.measure(constraints)
        val x = ((tab.ordinal - progress.value) * placeable.width).roundToInt()
        layout(placeable.width, placeable.height) { placeable.place(x, 0) }
    }
    return if (selected) placed else placed.clearAndSetSemantics {}
}
```

要点：

1. **动画值以 `State<Float>` 传入、在 measure 阶段读取**：若在组合作用域里读出来再当参数传，每帧会重组整个内容 lambda（连带三个页面的调用点）；现在每帧只重排。
2. **用 `place()` 而非 `graphicsLayer { translationX }`**：placement 是真实布局属性，坐标上报与 Haze 的背景采样都会跟着走，不会出现"页面动了、模糊背景没动"的错位。
3. **三页常驻组合**不变（原有注释随 helper 迁移）：切 tab 不重建，避免课表页首帧 `headerHeight` 回落到估算值、紧贴头部的日期带跳闪一次；滚动位置、折叠状态、当前周次全部存活。
4. **首帧不补播动画**：`animateFloatAsState` 初值即目标值，冷启动/进程重建后各页直接落在各自位置；`selectedTab` 仍是 `rememberSaveable`。
5. 非选中页仍 `clearAndSetSemantics {}`（离屏页对 TalkBack 隐藏）；离屏位置不在命中范围内，收不到点击/滚动。
6. 新增导入：`animation.core.{animateFloatAsState, tween, FastOutSlowInEasing}`、`runtime.State`、`kotlin.math.roundToInt`。

## 验证

1. `:app:compileDebugKotlin`、`:app:testDebugUnitTest` 均通过。
2. 已重新打包并就地安装到连接设备（`adb install -r`，未清数据）。
3. 上机清单：
   - 点相邻 tab：方向与 tab 左右一致，旧页滑出、新页滑入；导航栏自身不动。
   - 点日程 ⇄ 待办：课表页快速扫过（已确认的预期行为）。
   - 课表页滚动/折叠后切走再切回：滚动位置、折叠、周次都不丢，回来不闪。
   - 滚动过（头部已模糊）再切 tab：观察 Haze 模糊是否与网格对齐、无拖影。
   - 设置页覆盖层打开时切 tab 不受影响；动画期间新旧页都可点（正常）。

## 备注

跨两 tab 时中间页扫过是连续带子的必然结果。若观感上不想要，可改为 shared axis 风格（旧页滑出一屏、新页滑入一屏、中间页不出场），代价是每页各自的方向与层级/显隐处理；随时可换。
