# 底部导航栏（日程 / 课表 / 待办）实现计划

## 需求回顾

- 三个胶囊（pill）按钮：日程、课表、待办，悬浮于底部，图标在上、文字在下。
- 未选中：图标+文字 `#000000`，pill 背景白色（Surface）。
- 选中：pill 背景 = `PrimaryContainer`（`0x1F006FEF`），图标+文字 = `Primary`（`0xFF006FEF`）。
- 图标复用现有 drawable：日程 → `ic_day`（24 图标）、课表 → `ic_calendar`（日历点阵）、待办 → `ic_notes`（笔记+笔）。均为 24dp 单色矢量（fill `#212121`），用 `Icon(tint=...)` 覆盖即可。
- 底部全宽渐变遮罩：屏幕底部不透明 `#F2F4F6`（Background），向上渐变至透明，覆盖整个导航区域（含 pill 上沿以上一段，约 24dp），pill 浮在渐变之上；渐变层不拦截点击。
- 已确认决策：日程/待办用**简单占位页**；切换用 **rememberSaveable 状态 + when**（不引入 navigation-compose）；渐变**全宽覆盖导航区域**。

## 关键事实（已核实）

- 单模块 Compose 应用，BOM `2026.02.01`，仅 light 主题，无任何导航依赖（保持不变）。
- 入口 `MainActivity.kt`：`setContent { ClassppTheme { ScheduleScreen() } }`。
- `ScheduleScreen` 即课表页；其 Scaffold 无 bottomBar，网格 edge-to-edge，底部 inset 通过 `CourseGrid.contentPadding.bottom` 手动处理（ScheduleScreen.kt:93-99）。
- `Type.kt` 定义了 `labelMedium`（12sp Medium），**没有** `labelSmall` → 标签用 `labelMedium`。
- 阴影惯例参照 `WeekPill`（ScheduleHeader.kt:279-284）：`graphicsLayer { shape; clip; shadowElevation; spotShadowColor }`。
- `rememberCollapseState`（CollapseState.kt:96-99）是普通 `remember`，`collapseOffsetPx` 为 `private set` → 切 tab 会重置折叠状态，需小改。
- `values-en/strings.xml` 存在，新字符串需两处同步。

## 实现步骤

### 1. strings.xml（两处）
新增 `nav_schedule` / `nav_timetable` / `nav_todo`。

### 2. BottomNavBar.kt

```kotlin
enum class AppTab(@DrawableRes val iconRes: Int, @StringRes val labelRes: Int) {
    Agenda(R.drawable.ic_day, R.string.nav_schedule),
    Timetable(R.drawable.ic_calendar, R.string.nav_timetable),
    Todo(R.drawable.ic_notes, R.string.nav_todo),
}

@Composable
fun BottomNavBar(
    selectedTab: AppTab,
    onTabSelected: (AppTab) -> Unit,
    modifier: Modifier = Modifier,   // 调用方 align(BottomCenter)
)
```

尺寸常量：
- `PillHeight = 56.dp`、`PillBottomOffset = 12.dp`、`PillSpacing = 10.dp`、`PillShadowElevation = 8.dp`
- `NavReserve = PillBottomOffset + PillHeight = 68.dp`（供 ScheduleScreen 使用）
- `GradientOverhang = 24.dp`（渐变向上多出 pill 顶部的部分）
- 总高 helper：`@Composable fun navBarTotalHeight(): Dp = navigationBars bottom inset + NavReserve + GradientOverhang`

结构（一个 Box，渐变在底、pill 行在上，渐变层无 pointer input / 无 semantics）：

```
Box(fillMaxWidth, height = navBarTotalHeight) {
    // 渐变：Brush.verticalGradient(0f Transparent → 1f Background)，matchParentSize
    // Row：align(BottomCenter)，navigationBarsPadding + bottom=PillBottomOffset，
    //   horizontal padding 16dp，spacedBy(PillSpacing)
}
```

`NavPill`：
- `Modifier.height(56.dp).background(selected ? PrimaryContainer : colorScheme.surface, CircleShape)`，水平 padding 18dp，内部 `Column`（居中）：`Icon(painterResource, contentDescription = null, tint = selected ? Primary : Color.Black)` + `Spacer(4.dp)` + `Text(label, style = labelMedium, color 同 tint)`。
- 阴影（同 WeekPill 惯例）：`.graphicsLayer { shape = CircleShape; clip = true; shadowElevation = 8.dp.toPx(); spotShadowColor = Color.Black.copy(alpha = 0.15f) }`。
- 点击/无障碍：`Modifier.selectable(selected, role = Role.Tab, onClick)`；外层 Row 加 `selectableGroup()`；icon `contentDescription = null`（避免 TalkBack 重复朗读）。

### 3. PlaceholderScreens.kt
`AgendaScreen` / `TodoScreen`：`Box(fillMaxSize, Alignment.Center) { Text(stringResource(...), style = titleLarge) }`。

### 4. MainActivity.kt

```kotlin
setContent {
    ClassppTheme {
        var selectedTab by rememberSaveable { mutableStateOf(AppTab.Timetable) }  // 默认课表
        val stateHolder = rememberSaveableStateHolder()
        Box(Modifier.fillMaxSize()) {
            stateHolder.saveableState(selectedTab) {
                when (selectedTab) {
                    AppTab.Agenda -> AgendaScreen()
                    AppTab.Timetable -> ScheduleScreen()
                    AppTab.Todo -> TodoScreen()
                }
            }
            BottomNavBar(selectedTab, { selectedTab = it },
                Modifier.align(Alignment.BottomCenter))
        }
    }
}
```

状态放在导航栏外层 → 切 tab 导航栏不动；`SaveableStateHolder` 保留各页 `rememberSaveable` 状态（滚动位置、选中周等）。

### 5. ScheduleScreen.kt（contentPadding，93-99 行）
`bottom` 改为：navigationBars bottom inset `+ NavReserve`（68dp）。不加 GradientOverhang——渐变上段是半透明过渡区，内容本就应可见但渐隐；最后一行只需避开不透明 pill 与阴影。

### 6. CollapseState.kt
- `collapseOffsetPx` 增加 `internal fun restore(offset: Float)`（保持 `private set`）。
- `rememberCollapseState` 改用 `rememberSaveable(stateSaver = Saver(save = { it.collapseOffsetPx }, restore = { ... apply { restore(it) } }))`，使折叠状态在切 tab 后保留。

## 验证

1. `gradlew assembleDebug` 编译通过。
2. 模拟器手动检查（手势导航 + 三键导航各一次）：
   - 启动进入课表，导航栏悬浮在网格底部；滚到最后一行，行停在 pill 上方，不被遮挡。
   - 选中态：pill 背景浅蓝（PrimaryContainer），图标+文字 Primary 蓝；未选中：白底黑字黑图标。
   - 渐变：全宽，底部不透明 #F2F4F6 → 向上透明；内容滚到下方可见渐隐效果；渐变区域仍可正常滑动列表（不吞点击）。
   - 切到日程/待办显示占位页；切回课表，滚动位置、选中周、头部折叠状态保留；pill 位于手势条/三键栏之上，阴影可见。
   - 旋转屏幕 / 不保留活动：`selectedTab` 恢复。
   - TalkBack：每个 pill 朗读为可选标签及文字，无重复。
