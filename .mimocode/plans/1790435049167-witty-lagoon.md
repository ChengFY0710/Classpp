# 课表页顶栏渐变模糊 + 周数胶囊材质变化

## 目标（对照 4 张 mockup）

向下滑动、日期数字带（9 10 11 12 13，44dp）渐隐的过程中，顶栏（含状态栏条带）同步渐入**背景磨砂模糊**：顶部最强、向下渐弱，能看到课表网格从顶栏下方滚过；同时周数胶囊从扁平灰底渐变为半透明白 + 轻投影。回滑时对称淡出，完全展开后与现状无异。

## 已确认决策

| 项 | 选择 |
|---|---|
| 触发时机 | 随日期带渐隐**同步渐入**（进度 = 带滚动偏移 / 44dp） |
| 渐变形态 | 空间渐进：顶部 intensity 1 → 底部 0 |
| 胶囊材质 | 半透明白（~70% 白）+ 轻投影，`lerp` 随进度过渡 |
| 方案 | **Haze 1.6.10**（`dev.chrisbanes.haze:haze`），不动 Kotlin 2.2.10 |

## 架构要点（为什么要改结构）

现状是 `Column { ScheduleHeader; CourseGrid }`——内容永远画在顶栏**下方**，Compose 无法模糊"自己上面没有的东西"，必须让网格滚动到顶栏**背后**：

```
Box {
  CourseGrid(...)            // fillMaxSize，hazeSource，contentPadding.top = 顶栏实时高度
  ScheduleHeader(align TopStart)  // 后声明 → 盖在网格上，hazeEffect 在此
}
```

- 网格顶部偏移用 `LazyColumn` 的 `contentPadding.top`（**不是** modifier.padding）跟随顶栏实时高度：折叠期视觉与现在的 Column 上推完全等价；完全折叠后网格视口延伸到屏幕顶端，内容从顶栏背后滚过。
- 折叠时序不变：`CollapseState` 先消费 56dp 折叠，列表才开始滚动 → 日期带 offset 只会在完全折叠后增长 → **模糊天然只在折叠后出现**，无需额外门控。
- 模糊进度信号（ramp 与带渐隐同步，44dp 走完）：

```kotlin
val blurProgress by remember {
    derivedStateOf {
        if (listState.firstVisibleItemIndex == 0)
            (listState.firstVisibleItemScrollOffset / bandHeightPx).coerceIn(0f, 1f)
        else 1f
    }
}
```

`derivedStateOf` 只在输出 Float 变化时通知：带渐隐窗口内逐帧（必须），深滚时输出恒为 1 → **零新增重组**。index==0 分支不读 offset，回顶后也不订阅。

## 分步修改

### 1. 依赖
- `gradle/libs.versions.toml`：
  ```toml
  [versions]  haze = "1.6.10"
  [libraries] haze = { group = "dev.chrisbanes.haze", name = "haze", version.ref = "haze" }
  ```
- `app/build.gradle.kts`：`implementation(libs.haze)`（mavenCentral 已在 settings 配置）。

### 2. `ui/schedule/ScheduleScreen.kt`
- 上提 `val listState = rememberLazyListState()`、`val hazeState = rememberHazeState()`。
- `Column` → `Box`（结构见上），`nestedScroll` 仍挂网格；网格 modifier 追加 `.hazeSource(hazeState)`。
- 顶栏实时高度：`remember { mutableIntStateOf(估算初值) }`（≈ 状态栏 + 56dp + 日期行 + 星期行，避免首帧跳变），顶栏上 `onGloballyPositioned { headerHeightPx = it.size.height }` 写入，转成 `PaddingValues(top = …)` 传给网格（保留原底部导航栏 inset）。
- 计算 `blurProgress`（见上式；`DateBandHeight` 改为 `internal` 供此处取 px），与 `hazeState` 一起传给 `ScheduleHeader`。

### 3. `ui/schedule/CourseGrid.kt`
- 内部 `rememberLazyListState()` 改为参数 `state: LazyListState = rememberLazyListState()`（DateBand 已接收 listState，默认值保住 Preview）。
- `private val DateBandHeight` → `internal val DateBandHeight`。
- 其余（渐隐 graphicsLayer、网格线）不动——offset 语义在新结构下不变。

### 4. `ui/schedule/ScheduleHeader.kt`
- 新增参数 `blurProgress: Float = 0f`、`hazeState: HazeState? = null`（默认值保住 Preview）。
- 根修饰符链（background 已在 `windowInsetsPadding` 外层、覆盖状态栏条带，haze 插在两者之间，内容画在最上）：
  ```kotlin
  .fillMaxWidth()
  .background(surface)                       // 兜底：progress≈0 时与现状逐帧一致
  .then(if (hazeState != null && blurProgress > 0f)
          Modifier.hazeEffect(hazeState) {
              alpha = blurProgress            // 整体透明度渐入 → 与 surface 无缝衔接
              blurRadius = 20.dp
              progressive = HazeProgressive.verticalGradient(1f, 0f)   // 顶强底弱
              tints = listOf(HazeTint(Color.White.copy(alpha = 0.30f)))
              noiseFactor = 0f
          } else Modifier)
  .windowInsetsPadding(WindowInsets.statusBars)
  ```
  常量（20dp / 0.30f 白度）为可调项，实现时按 mockup 目测微调。
- `WeekPill` 增加 `blurProgress: Float = 0f`：
  - 底色：`lerp(colorScheme.background, Color.White.copy(alpha = 0.7f), blurProgress)`
  - 投影：`Modifier.graphicsLayer { shadowElevation = 6.dp.toPx() * blurProgress; shape = CircleShape; clip = true }`（draw 阶段读值，不引发重组；progress=0 时 elevation=0 与现状一致）。
  - 文字/图标/`collapsedEndPad=110dp`/RTL 分支（Layout 测量块内）全部不动。
- 可选：补一个 `blurProgress = 1f` 的模糊态 `@Preview`。

## 边界与风险

- **平台降级**：Haze 1.6 默认 API 31/32 开模糊、**API ≤30 自动降级为半透明 scrim**（无需代码）；RenderScript 模糊实验性，**不启用**。API 33+ 渐进模糊成本≈0，31/32 线性渐进约 2x 绘制——低端机卡顿时改 `preferPerformance = true` 或 `mask`。
- **Compose 二进制兼容**：Haze 1.6.10 编译于 Compose 1.8.2，项目 BOM 2026.02.01 更新；老库+新 runtime 通常安全，首跑盯 `NoSuchMethodError`/`VerifyError`，出问题再评估升 Haze 2.0 + Kotlin 2.4.20（届时 API 全变，另行确认）。Kotlin 元数据 2.1.0 被 2.2.10 消费：无问题。
- **渐进强度是否同时压制 tint**（还是只压 blurRadius）文档未写明——实现时验证；若底部发白残留，把 tint 改为随 `blurProgress` 联动或换 `mask`。
- 菜单打开仅暂停折叠（`menuOpen`），不影响模糊逻辑；`DropdownMenu` 是独立 Popup，不受 haze 影响。
- `headerHeightPx` 首帧为估算值，可能 1 帧错位（onGloballyPositioned 首绘前通常已纠正）。
- 性能：模糊仅在 `blurProgress > 0`（即带渐隐之后）处理；`hazeSource` 常驻有 layer 录制开销，首版接受，若 Layout Inspector 见开销再优化开关时机。
