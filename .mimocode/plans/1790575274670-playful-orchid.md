# 课程跨节（多节次 span）实现计划

## 目标

编辑课表时，添加课程面板可选择**结束节次**（起始 = 点击的格子，默认结束 = 起始，即跨 1 节）；课程卡片在网格中跨 N 行渲染，顶部显示起始节次开始时间、底部显示末结束节次结束时间（如第 1–2 节 → 8:00 / 11:50），卡片盖住行分界网格线（见用户截图微积分卡）。

用户已确认的交互决策：
- 只加"结束节次"选择器，起始节次来自点击的格子；
- 选择器用**节次芯片按钮**（风格仿现有"上课周数"方格），只允许选 ≥ 起始 且在范围内的节次。

## 现状要点（已核实）

- **数据层已完整支持 span**：`data/model/ScheduleModels.kt:92-107` `CourseEntry.span`（默认 1）+ 计算属性 `endSlot`；`data/ScheduleValidator.kt` R10（`MAX_SPAN = 5`，节次/跨度范围 :113-119）、R13（span 相交 + 周数相交 → 冲突 :137-155）；持久化 JSON `encodeDefaults=true`，`span` 已随文件往返（`ScheduleJsonRoundTripTest` 覆盖）。**数据层零改动。**
- **UI 层刻意单节**：`ui/schedule/ScheduleModels.kt:7-19` 渲染模型 `Course` 无 span；`ScheduleAdapters.kt:21-29` 丢弃 span；`AddCoursePanel.kt:154` 硬编码 `span = 1`；`CourseCard.kt` 用单个 `slot` 的起止时间。
- **网格结构**：`CourseGrid.kt` — 每节次一个 `GridRow`（固定高 `GridRowHeight = 150.dp`，5 个 `weight(1f)` 单元格），网格线画在各行 `drawBehind`；页高 `= GridRowHeight × 节数 + 首尾`（:94-95）。编辑态隐藏日期带（`showDates = editSession == null`，`ScheduleScreen.kt:343`）。
- 资源：默认 `values/` 是中文、`values-en/` 是英文（无 values-zh），新字符串两处都加。
- 现有单元测试全部在数据层；无 Compose UI 测试。

## 渲染方案：WeekPage 内加"跨节卡叠加层"（overlay）

否决的备选：
- **起始格内溢出 + zIndex**：各行是 `Column` 的平级兄弟，后续行的 `drawBehind` 网格线在起始行**之后**绘制会横穿溢出的卡片；子节点 `zIndex` 无法越过父节点的后续兄弟。
- **重构为按天列绝对定位**：需重推横向网格线/接缝线/日期带对齐，回归风险大。

Overlay 做法：`WeekPage` 的 `Column` 外包一层 `Box`（`graphicsLayer` + 接缝 `drawBehind` 移到 Box 上，保留 Pager 图层缓存），`Box` 内第二个子节点为镜像叠加列——**完全复刻** `Row/weight(1f)/CellPadding` 结构（同 x 对齐），行高用 `GridRowHeight` 的 Spacer/Row 镜像（同 y 对齐），后绘制 ⇒ 不透明卡片自然压过各行网格线；空节点无 pointerInput ⇒ 点击穿透，不影响现有触控与翻页。

卡片高度公式：`span × GridRowHeight − CellPaddingTop(2dp) − CellPadding(3dp)`，与单格内容盒完全一致，四边内缩对齐普通卡片。

### 6. 网格 — `ui/schedule/CourseGrid.kt`
**6a. `GridRow`（:293-345）续格抑制：**
```kotlin
val course = courses.findAt(day, slot.id)
val covered = courses.isContinuationAt(day, slot.id)
val add: (() -> Unit)? = if (editMode && onAddClick != null && !covered) { { onAddClick(day, slot) } } else null
when {
    course == null && add != null -> AddCourseCard(...)
    course != null && course.span == 1 -> CourseCard(...)  // 单节照旧
    // span > 1 的起始格与 covered 格：留空（跨节卡由叠加层绘制）
}
```

**6b. `WeekPage`（:159-206）包 Overlay：** `Column`（`graphicsLayer{}` + 接缝 `drawBehind` 从 Column 移到外层 `Box`）+ 叠加列：
```kotlin
Box(Modifier.graphicsLayer { }.drawBehind { /* 接缝线原样 */ }) {
    Column(Modifier.fillMaxSize()) { /* 原内容不动 */ }
    // 跨节卡叠加层：后绘制压过网格线；无 handler → 点击穿透
    Column(Modifier.matchParentSize()) {
        if (showDates) Spacer(Modifier.height(DateBandHeight))  // 与日期带等高对齐
        timeSlots.forEach { slot ->
            Row(Modifier.fillMaxWidth().height(GridRowHeight)) {
                for (day in 1..5) {
                    val course = content.courses.findAt(day, slot.id)
                    Box(Modifier.weight(1f).fillMaxHeight()
                        .padding(start = CellPadding, end = CellPadding, top = CellPaddingTop, bottom = CellPadding)) {
                        if (course != null && course.span > 1) {
                            val lastIdx = (slot.id - 1 + course.span - 1).coerceAtMost(timeSlots.lastIndex)
                            val effSpan = lastIdx - (slot.id - 1) + 1
                            CourseCard(
                                course = course, slot = slot,
                                endTime = timeSlots[lastIdx].endTime,
                                modifier = Modifier.fillMaxWidth()
                                    .height(GridRowHeight * effSpan - CellPaddingTop - CellPadding),
                                onClick = if (!course.active && editMode && onAddClick != null)
                                    ({ onAddClick(day, slot) }) else null,
                            )
                        }
                    }
                }
            }
        }
    }
}
```
`pageHeight`（:94-95）不变；编辑态/普通态 y 偏移均由 `showDates` 镜像 Spacer 吸收。

## 边界情况（已核实结论）

| 场景 | 处理 |
|---|---|
| 结束节次越界 | 芯片只开放到 `min(slotCount, start+4)`；`submit()` 再 coerce；渲染端 `coerceAtMost(timeSlots.lastIndex)` 防御 |
| 设置页减少节数 < 已有课 endSlot | 已被 `setSlots` 全量校验拦截（R10 → `CoursesOutOfRange`），无需加载期归一化 |
| 跨节覆盖格的点击 | `isContinuationAt` 抑制添加卡 → 点击无操作（与普通课程卡点击无操作一致） |
| 跨节卡 + 置灰（本周不上） | overlay 卡在编辑态可点 → 打开起始格添加面板，行为同单节置灰卡 |
| 校验冲突 | R13 已按 span 相交判定，面板复用现有冲突文案 |
| MAX_SPAN=5 | 芯片封顶 + submit coerce + 校验器三重保障 |
