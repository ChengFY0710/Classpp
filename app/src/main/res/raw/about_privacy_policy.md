**最后更新：2026-11-11**

**Class Plus Plus（Classpp / Class++，以下简称“本项目”）** 是一款本地优先的课表应用。本政策说明应用会处理哪些数据、为何处理、可能发送给谁，以及您可以如何控制这些数据。

## 1. 我们收集什么

- **不收集**：作者不运营用于收集用户数据的服务器；应用不包含广告、统计分析或崩溃上报 SDK，也不读取通讯录、短信、位置或麦克风。
- **仅保存在本地**：课表、时间方案、待办、标签、日程背景图、AI 对话记录与对话图片副本、应用设置、远端学校声明缓存等，默认存储在您的设备上。
- **敏感凭据**：您为学校保存的账号密码与 AI 服务 API Key 会经 Android Keystore 加密后保存在应用私有目录（保存凭据仅部分学校支持）；WebView 登录产生的会话 Cookie 保存在应用私有目录。

## 2. 数据如何被使用

本地数据仅用于实现您可见的功能：展示课表与待办、发送提醒、同步学校课程、AI 对话、导入导出备份与个性化设置。作者不会将这些数据用于广告、用户画像或出售。

## 3. 第三方数据流

除以下您主动触发的场景外，应用不会向第三方发送您的数据。第三方如何处理数据受其自身政策约束，作者无法控制。

### 3.1 学校系统 / 教务系统

- 当您登录、同步或开启自动同步时，应用会向您选择的学校域名发送账号、密码、Cookie 或同步请求，并接收课程、待办等数据。
- 请求由您的设备直接发往学校系统，作者不中转、不记录。
- 请自行确认使用行为符合学校规定与第三方服务条款。

### 3.2 Wakeup 口令导入

- 使用口令导入时，您提供的口令会发送至 `api.wakeup.fun`。
- 应用会从公开开源仓库下载适配脚本 `wake_up.js`，并在无头 WebView 中执行；脚本由第三方作者维护。
- 因第三方服务、脚本行为或条款产生的后果由您自行承担。

### 3.3 远端学校列表

- 「更新学校列表」为纯手动操作，默认关闭；应用不会在启动或后台自动拉取。
- 更新时，应用会访问作者维护的 Gitee 仓库（`classpp_schoolsync`），下载 JSON 声明并缓存在本机。
- 声明不包含远端 JavaScript，应用会对域名等字段做硬校验；首次连接某所远端学校时会展示学校名与登录域要求您确认。

### 3.4 AI 服务商（BYOK）

- 使用 AI 对话时，应用会将聊天内容、随消息发送的图片，以及自动注入的上下文（课表、作息、最多 30 条未完成待办、分组、标签）发送至您选择的服务商。
- 请求由您的设备直连服务商（包括您自定义的端点），作者不参与、不中转、不记录。
- 服务商的隐私政策、数据留存、内容审核、计费与可用性由该服务商决定；请在使用前阅读其政策，不要发送身份证号、密码、银行卡、健康信息等敏感内容。
- 若服务商位于境外，跨境传输风险及合规责任由您自行判断和承担。

## 4. 系统备份与手动导出

- 应用开启了 Android 系统备份（`allowBackup`），并配置了云备份与换机迁移规则。账号密码、Cookie、API Key 等敏感文件已被排除；课表、待办、标签、背景图、AI 对话记录与对话图片等仍可能被系统备份至您的云端或随换机迁移。
- 系统备份的范围与行为由操作系统、设备厂商及您的账号设置决定，作者无法控制。若您不希望数据进入云端备份，请自行关闭系统备份或使用工作资料/独立设备隔离。
- 「数据管理」中的导出备份会生成一个**未加密的 ZIP 包**，包含课表、待办、标签、背景图、AI 对话文本等（不含凭据、API Key 与 AI 对话图片附件）。请妥善保管，避免上传至公开网盘、聊天工具或其他可能被他人访问的位置。

## 5. 权限说明

应用会请求或使用以下系统能力，是否授予由您自行判断：

- **网络访问**：访问学校系统、Gitee 远端学校仓库、Wakeup 服务及您配置的 AI 服务商；
- **通知**：课程/待办提醒与同步结果通知；部分 Android 版本会使用 promoted ongoing（Live Updates）样式；
- **日历读写**：读取日历账户列表以选择写入目标，并向您选择的日历写入待办事件；
- **精确闹钟与开机自启**：重排提醒闹钟与每日同步任务；
- **`SET_ALARM`**：拉起系统时钟应用创建一次性闹钟（普通权限，安装即授予）；
- **相机**：AI 对话拍照通过系统相机应用完成，应用不直接申请相机权限；
- **文件选择 / Photo Picker**：用于选择图片、导入导出备份，不额外申请存储权限。

拒绝授权可能导致对应功能不可用。

## 6. 数据保留与删除

- 本地数据会一直保存在您的设备上，直到您在应用内删除、清除应用数据或卸载应用。
- 作者不运营服务器，因此不存在需要向作者申请删除的服务器端副本。
- 您手动导出的备份文件、系统云备份以及已发送给学校系统或 AI 服务商的数据，需要您分别在对应位置管理或删除。

## 7. 安全

- 应用使用 Android Keystore 加密保存凭据与 API Key，并将敏感数据存放在应用私有目录；但本项目**未经安全审计**，无法保证绝对安全。
- 设备被 root/越狱、被解锁、植入恶意软件、系统漏洞被利用或备份文件被他人获取时，数据仍可能泄露。请自行做好设备与备份管理。

## 8. 未成年人

本项目并非面向儿童设计，不主动收集儿童个人信息。未成年人应在监护人指导下使用本项目，并由监护人对其使用行为负责。

## 9. 政策更新

本政策可能随功能变化而更新，更新后自发布之时起生效。重大变更会在应用内或项目仓库中说明。
