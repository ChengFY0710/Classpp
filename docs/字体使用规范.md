# Classpp 字体使用规范

> **状态**：当前生效
> **基准**：`635813f`（2026-10-29）+ 浮层顶栏标题改用 `topBarTitle`、待办卡属性行追加 tnum、2026-10-31 字号档位调整（未提交）
> **适用范围**：`app/src/main/java` 下全部 Jetpack Compose 文字
> **唯一事实源**：`ui/theme/TextTokens.kt`
> **历史文档**：`.mimocode/docs/字体样式规范.md`（扫描审计与阶段 0–4 迁移记录，未纳入版本库）
> **自动守卫**：`app/src/test/java/com/fangyi/classpp/ui/theme/FontUsageRulesTest.kt`

## 0. 快速规则

1. **业务代码不写裸字号。** 不写 `N.sp`，不写 `TextStyle(...)`，不覆盖 `fontSize` / `lineHeight` / `letterSpacing` / `fontFamily`。
2. **字号只有 UI 六档 + 特殊展示四档 + 展示数字三档。** UI：`11 / 12 / 14 / 16 / 20 / 23sp`；特殊展示：`24sp`（台历副标题）、`17sp`（周数选择胶囊、课表日期带）、`22sp`（周数选择卡内数字）、`40sp`（横向数字滚轮）；展示数字：`32 / 52 / 64sp`。
3. **字重只有三档。** `Normal(400)` 正文，`Medium(500)` 标签/元信息/行值，`SemiBold(600)` 标题/按钮/选中态。`Bold` 禁用；`Black` 仅台历思源宋体。
4. **行高有节奏，字距基本为 0。** 12sp→16、14sp→20、16sp→20/24、20sp→24、23sp→28（倒计时数字继承 24）；只有 `pageTitle` / `calendarSubtitle` 用 `-0.3sp`，`actionLabel` 用 `0.8sp`。
5. **会变的数字必须等宽。** 时间、倒计时、滚轮、时间轴用带 `tabularNumbers()` 的 token，或对已有样式追加 `.tabularNumbers()`。
6. **token 不含颜色。** 颜色由 `colorScheme` / `ClassppColors` 或 `MaterialTheme.classppTextStyles` 提供。

## 1. 文件职责与取用顺序

| 文件 | 职责 | 什么时候用 |
|---|---|---|
| `ui/theme/TextTokens.kt` | 56 个语义 token，业务文字的唯一来源 | 业务文字的主入口 |
| `ui/theme/Type.kt` `Typography` | Material3 15 个槽位全部显式定义 | M3 组件内部、通用正文 |
| `ui/theme/Type.kt` `ClassppTextStyles` | 7 个带颜色的角色样式 | 设置页、浮层、行卡、表单 |
| `ui/theme/Fonts.kt` | `SerifDisplay`（思源宋体 Heavy 子集） | 仅台历大日期/节日 |
| `ui/theme/Theme.kt` | 装配 `MaterialTheme` 与 `CompositionLocal` | 主题入口 |

取用顺序：

1. 设置页 / 浮层 / 行卡 / 表单 → `MaterialTheme.classppTextStyles.*`（自带颜色）
2. 其他有明确语义的文字 → `ClassppTextTokens.*`（颜色在调用处决定）
3. M3 组件或没有专用 token 的通用正文 → `MaterialTheme.typography.*`
4. 禁止直接依赖 `LocalTextStyle` 或裸 `N.sp`（`LocalTextStyle` 唯一例外见 §14.9）

| 16sp | 卡片标题、行卡 label/value、按钮、日历、课表切换卡标题、滚轮单位 | `cardTitle`、`fieldLabel`、`bodyValue`、`buttonText`、`calendarDay`、`listRowTitle`、`wheelUnit` |

| 20sp | 浮层/对话框/空态标题、设置周数/重复方格 | `sheetTitle`、`dialogTitle`、`emptyTitle`、`weekCell` |
| 22sp | 周数选择卡内数字（特殊展示） | `weekGridNumber` |

| 40sp | 横向数字滚轮（特殊展示） | `horizontalWheelNumber` |
| 52sp | 台历节日 | `displayDateMark` |
| 64sp | 台历大日期 | `displayDate` |

补充规则：

- **特殊展示字号只有四档**：`24sp` 仅台历日期副标题（`calendarSubtitle`）；`17sp` 仅课表页顶栏周数选择胶囊（`weekPill`）与课表日期带（`courseGridDate`）；`22sp` 仅周数选择卡内数字（`weekGridNumber`）；`40sp` 仅横向数字滚轮（`horizontalWheelNumber`）。它们不进入常规阶梯，不要挪作正文或其他标题。
- **23sp 是 UI 最大常规档**：页面顶栏日期/标题、详情标题与倒计时数字统一使用，不再属于特殊展示字号。
- **已废弃档位**：`10 / 15 / 25 / 36sp`，禁止新增。
- 需要新档位时，先在 `TextTokens.kt` 增加语义 token，再同步本表与守卫测试，不能直接在调用处写 `N.sp`。

## 3. 字重阶梯

| 字重 | 用途 | 典型 token |
|---|---|---|
| `Normal(400)` | 正文、描述、元信息、次级说明、倒计时单位 | `secondaryText`、`metaText`、`settingsDescription`、`tagChip`、`countdownUnit` |
| `Medium(500)` | 行值/输入值/占位、说明、分组标题、标签、时间、动作标签、文字按钮、底栏、周数方格、滚轮数字、滚轮单位 | `bodyValue`、`placeholder`、`secondaryTextLarge`、`sectionTitle`、`metaTextSmall`、`actionLabel`、`textButton`、`navLabel`、`weekGridNumber`、`weekCell`、`timeWheelNumber`、`wheelUnit` |
| `SemiBold(600)` | 所有标题、按钮、选中态、分组头动作、日历日号/星期、日历/课表回跳动作、周胶囊 | `pageTitle`、`cardTitle`、`buttonText`、`sectionAction`、`calendarDay`、`calendarAction`、`weekPill` |
| `Black(900)` | 仅 `displayDate` / `displayDateMark`（思源宋体） | `displayDate`、`displayDateMark` |
| `Bold(700)` | **禁用** | — |

状态字重：

- 选中/未选中只允许在 `Medium` 与 `SemiBold` 之间切换（如周数方格、滚轮数字）。
- 同一组件内不要混用 `Bold` 与 `SemiBold` 表达同一强调级别。

## 4. 行高与字距

### 4.1 行高

| 字号 | 行高 | 场景 |
|---:|---:|---|
| 11sp | 13sp | 底栏标签（`navLabel`） |
| 11sp | 16sp | 课表课程卡教师/地点行（`courseCardTeacher`、`courseCardLocation`）、时间轴当前时刻胶囊（`timelineNowChip`） |
| 12sp | 16sp | 紧凑卡片标题、元信息、标签、时间轴 |
| 14sp | 16sp | 顶栏/编辑栏图标下动作标签（`actionLabel`，紧行高例外，见更新记录） |
| 14sp | 20sp | 描述、元信息、分组标题、分组头动作、确认框正文 |
| 16sp | 20sp | 单行卡片标题、日历星期、课表切换卡标题 |
| 16sp | 24sp | 表单/正文（继承 `bodyLarge`）、日历日号、滚轮单位（继承） |
| 17sp | 20sp | 周数选择胶囊（`weekPill`） |
| 17sp | 24sp | 课表日期带（`courseGridDate`） |
| 20sp | 24sp | 浮层标题、空态标题、设置周数/重复方格 |
| 22sp | 24sp | 周数选择卡内数字（`weekGridNumber`） |
| 23sp | 28sp | 页面顶栏日期/标题（`pageTitle`）、详情标题（`detailTitle`） |
| 23sp | 继承 24sp | 倒计时数字（`countdownNumber`） |
| 24sp | 28sp | 台历副标题（`calendarSubtitle`） |
| 32/40/52/64sp | 继承或紧行盒 | 滚轮数字、台历大日期 |

规则：

- 中文正文行高按字号的 **1.25–1.5 倍**；单行标签 1.2–1.3 倍；展示数字可更紧。
- **禁止中文正文 `lineHeight == fontSize`**。
- 未显式写 `lineHeight` 的 token 继承 `LocalTextStyle`（`Typography.bodyLarge` 的 24sp / 0sp），这是有意为之，不要逐处补行高。
- `displayDate` / `displayDateMark` 的 `lineHeight = 24sp` 是台历几何的**紧行盒锚点**，不是排版遗漏，不要“修正”。

### 4.2 字距

| 值 | 使用范围 |
|---|---|
| `0sp` | 其余全部文字 |
| `0.8sp` | 仅 `actionLabel`（顶栏/编辑栏图标下动作标签，14sp） |
| `-0.3sp` | 仅 `pageTitle`、`calendarSubtitle` |

不再使用 Material 默认的中文正字距（`0.1/0.15/0.25/0.5sp`）。

## 6. 三种取用方式

### 6.1 业务文字：`ClassppTextTokens`

```kotlin
Text(
    text = course.name,
    style = ClassppTextTokens.compactCardTitle,
    color = MaterialTheme.colorScheme.onSurface,
)
```

### 6.2 设置页 / 浮层 / 行卡：`MaterialTheme.classppTextStyles`

角色样式自带颜色，优先使用：

```kotlin
Text(
    text = label,
    style = MaterialTheme.classppTextStyles.fieldLabel,
)

Text(
    text = value,
    style = MaterialTheme.classppTextStyles.fieldValue,
)
```

### 6.3 M3 组件 / 通用正文：`MaterialTheme.typography`

```kotlin
Text(
    text = message,
    style = MaterialTheme.typography.bodyMedium,
)
```

### 6.4 允许的微调

只允许 `copy` 颜色与选中态字重；样式本身仍来自 token：

```kotlin
Text(
    text = value,
    style = ClassppTextTokens.weekCell.copy(
        color = MaterialTheme.colorScheme.primary,
        fontWeight = FontWeight.SemiBold,
    ),
)
```

会变化的数字：

```kotlin
Text(
    text = TimeText.format(minutes),
    style = MaterialTheme.classppTextStyles.fieldLabel.tabularNumbers(),
)
```

## 8. 数字与等宽数字

`tabularNumbers()` 是唯一允许写 `fontFeatureSettings = "tnum"` 的地方，定义在 `ui/theme/TextTokens.kt`。

已内置 tnum 的 token：

`metaTextSmall`、`courseCardMeta`、`timelineLabel`、`timelineNowChip`、`dateWheelNumber`、`timeWheelNumber`、`horizontalWheelNumber`、`countdownNumber`、`countdownUnit`。

使用规则：

- 任何会随数据变化的数字（时间、倒计时、滚轮、时间轴、时间胶囊）都必须等宽，避免换值时左右抖动。
- 待办卡属性行（时间/截止/重复）统一等宽：NoteCard 的 `TimeProperty` 默认样式为 `noteProperty.tabularNumbers()`；TodoInboxCard 非紧凑形态同样追加，紧凑形态直接用 `metaTextSmall`（自带 tnum）。
- 已有 token 不带 tnum 时，允许追加 `.tabularNumbers()`，不要手写 `fontFeatureSettings`。
- Canvas 绘制的滚轮文字从 token 读取 `fontSize` / `fontWeight`，不要另起字号。

## 11. 新增 / 修改文字的流程

1. **认角色**：先在“场景对照表”里找到它属于哪个场景。
2. **选入口**：设置/浮层/行卡/表单 → `classppTextStyles`；其他 → `ClassppTextTokens`；M3 组件 → `Typography`。
3. **选 token**：优先复用现有 token，不新建近义 token。
4. **补颜色**：用 `colorScheme` / `ClassppColors`，不写死颜色。
5. **数字加 tnum**：会变化的数字追加 `.tabularNumbers()` 或选带 tnum 的 token。
6. **确需新档位**：先在 `TextTokens.kt` 新增语义 token，再同步本规范与 `FontUsageRulesTest`；不要在调用处直接写值。
7. **验收**：跑第 13 节的编译、单测和扫描命令。
