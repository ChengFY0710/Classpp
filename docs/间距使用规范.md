# Classpp 间距使用规范

> **状态**：当前生效
> **基准**：`d41a99ee`（2026-11-25 全量复核：380 个 Kotlin 文件、1017 处 `.dp` 字面量、14 个全局 token）
> **适用范围**：`app/src/main/java` 下全部 Jetpack Compose 间距与控件尺寸——`padding`、`Arrangement.spacedBy`、`Spacer`、宽/高/`heightIn` 等非负 `dp` 值
> **唯一事实源**：`ui/theme/Spacing.kt`（14 个 token）
> **姊妹规范**：`docs/字体使用规范.md`（字号/行高/字距）、`docs/颜色使用规范.md`（取色）
> **自动守卫**：暂无（验收用第 9 节扫描命令；字体/颜色已有 `FontUsageRulesTest` / `ColorUsageRulesTest`，间距守卫列入 §11.12）

## 0. 快速规则

1. **跨文件复用的间距一律走全局 token。** 页面边距、组节奏、行高下限、编辑动作栏几何这类两处以上使用的值，只从 `ui/theme/Spacing.kt` 取；不在业务文件里定义与它同值或同义的私有常量。
2. **取值走阶梯，不发明新值。** 页面与分组节奏只从 2 / 3 / 4 / 5 / 6 / 8 / 10 / 12 / 14 / 15 / 16 / 18 / 20 / 24 / 32dp 里取（分工见 §2.1）；1dp 只用于描边与分割线。组件内部几何（开关、滚轮、环图等）按 §2.4 由组件自己持有，**不得外溢为页面节奏**。
3. **横向边距有两个家族，不互相「统一」。** 页面/浮层内容一律 `PageHorizontalSpacing`（12dp，设置页与浮层卡片同宽对齐）；课表顶栏、日程顶栏、底部导航是 33dp 家族（两页顶栏互相对齐的设计，`DayGeometry.kt` 注释）；浮层顶栏行内距 15dp 是「胶囊贴边更收」的刻意值（`TopBarRowHorizontalPadding` 的 KDoc）。AI 识别页预览图的 36dp 是叠在 12dp 页边距之上的**图片内缩**，不是第三种页面边距。
4. **纵向节奏两档分工。** 组内「卡↔卡」10dp（`CardSectionSpacing`）、组与组之间 18dp（浮层 `SheetSectionSpacingBetween` / 设置页 `SettingsSectionSpacing` 同值）。同一页面内只用一套组间节奏；AI 对话的消息内卡片（思考块↔气泡↔工具卡）沿用 10dp。
5. **圆角不归本文管。** 一律走 `ui/theme/Shape.kt` 的连续曲率形状常量（见 §6.1）；不要用间距值顺手写 `RoundedCornerShape`。
6. **确需新 token：** 先在 `Spacing.kt` 增加语义 token 并写中文 KDoc（说明谁在用、与相邻 token 的分工），再同步本规范第 3 节与场景表；不要先在业务代码里写字面量再回头补。

## 1. 文件职责与取用顺序

| 文件 | 职责 | 什么时候用 |
|---|---|---|
| `ui/theme/Spacing.kt` | 14 个全局间距/尺寸 token（KDoc 说明分工） | 页面边距、组节奏、行高下限、行卡内距、编辑动作栏几何等跨文件复用值 |
| `ui/theme/Shape.kt` | 20 个公开连续曲率形状 + `dayTaskCardShape(...)`（另有 2 个私有半径） | 所有圆角（阶梯见 §6.1） |
| `ui/day/DayGeometry.kt` | 日程页台历转场几何 22 个 dp token（402×893dp 设计稿量取，逐条 KDoc） | 仅日程页台历/转场；其他页面禁止借用 |
| `ui/theme/LiquidGlass.kt` | 玻璃材质两档参数（`Pill` blur 4 / lens 10·14、`NavPill` blur 4 / lens 16·32） | 仅玻璃观感参数；胶囊高度由使用处常量决定 |
| `ui/navigation/BottomNavBar.kt` | `NavReserve = PillBottomOffset(8) + PillHeight(56) = 64dp`，另有 `GradientOverhang` 40 / `NavBarTransitionHeadroom` 20 | 页面内容底部为导航栏预留空间、底栏遮罩与转场余量 |
| 组件文件级常量 | 单文件专用的间距与组件几何（含 `private` / `internal`，语义化命名 + KDoc，当前 311 个） | 仅本文件使用的值 |
| 行内字面量 | 2–4dp 级微调、一次性几何 | 门槛见 §4.3 |

取用顺序：

1. 两处以上文件使用（或属于第 2 节阶梯中的全局节奏）→ `ui/theme/Spacing.kt` token
2. 日程页台历几何 → `DayGeometry.kt`；圆角 → `Shape.kt`
3. 单文件内两处以上使用 → 文件私有常量（语义化命名 + KDoc）
4. 单次使用的微调/几何 → 行内字面量（值仍须在阶梯内）
5. **禁止**：定义与全局 token 同值同义的镜像常量；把全局节奏值写成字面量

## 2. 间距阶梯

### 2.1 间距（gap / padding）

| 档位 | 用途 | 现状表达 |
|---:|---|---|
| 1dp | 分割线/描边/网格线粗细（非间距） | 字面量（19 处：`DateSelectionCard`、`PopupMenuCard`、`DayTimeline`、`CourseGrid`、桌面小组件等） |
| 2dp | 紧贴堆叠：时间轴格间隙、任务卡贴邻（`DayTaskColumnGap` / `DayTaskVerticalGap`）、进度裁剪、标题↔属性行 | 字面量/私有常量 |
| 3dp | 课表密集格行距与色条、设置页标题↔说明（`InfoHeaderTitleDescriptionGap`）、卡片元信息行距、空态标题↔说明 | 私有常量 |
| 4dp | 微间距：tag 内距、课表格子内距（`CardPaddingStart`）、Markdown 段间、空态标签间距 | 字面量为主 |
| 5dp | 图标↔其下方标签（`EditActionLabelGap`）、导航胶囊图标上侧内距、搜索框上浮补偿（`SheetSearchPinLift`） | token / 私有常量 |
| 6dp | tag 间距、小胶囊图标↔文本、台历卡顶入画（`DayCardTopInset`）、动作行顶距（`EditBarTopPadding`）、导航胶囊标签下侧内距 | 私有常量为主 |
| 8dp | 分组「标题↔首卡」（`CardSectionTitleSpacing`）、动作块水平内距（`EditActionInnerPadding`）、设置页头部卡图标↔标题、信息条图标↔文字、空态图标↔标题 | token + 私有常量 + 字面量 |
| 10dp | 组内「卡↔卡」（`CardSectionSpacing`）、待办收件箱卡间距、AI 消息内卡片节奏、信息胶囊行间距 | token + 私有常量 |
| 12dp | **全局主力档**：页面横向边距（`PageHorizontalSpacing`）、卡片横向内距、行卡图标↔文本、AI 对话页边距 | token 为主 |
| 14dp | 行卡纵向内距（与 16 配对）、AI 气泡内距、设置页自定义行前导槽↔文字 | token + 私有常量 |
| 15dp | 浮层/选择卡顶栏行横向内距（`TopBarRowHorizontalPadding`，胶囊贴边更收） | token |
| 16dp | 行卡横向内距（与 14 配对）、待办顶栏胶囊内距、信息条内容内距 | token + 私有常量 |
| 18dp | 浮层组间（`SheetSectionSpacingBetween`）、设置页组间（`SettingsSectionSpacing`）、底栏胶囊间距 | token |
| 20dp | 待办分组间距（`TodoScreen.SectionSpacing`）、台历卡间距（`DayCardGap`）、设置页信息头部卡下留白（`InfoHeaderBottomPadding`） | 私有常量 |
| 24dp | 区块间距（确认框标题上 24）、标准图标边长、设置页信息头部卡上留白、空态描述左右留白 | 字面量 + 私有常量 |
| 32dp | 大图标、底部渐隐延伸（`BottomScrimExtend`）、设置页头部卡横向留白（`InfoHeaderHorizontalPadding`）、概览周列宽 | 字面量 + 私有常量 |

补充规则：

- **0 不是间距值**：`0.dp`（86 处）只用于清零、复位与堆叠抵消，合法。
- 阶梯是「现状 + 约束」：已有私有常量的档位（3/20）不要求立即迁移，但**新代码**选档时按本表，并优先用已有 token。
- 需要新档位（如 9/11/13/17dp）时，先在本规范登记用途与理由，再写代码；不接受无登记的魔法数字。
- **13 / 28 / 34 / 36 / 38 / 46 等非节奏值**只允许作为组件自有几何（§2.4）或一次性尺寸，不得拿来当页面边距或组间节奏。

## 4. 三种取用方式

### 4.1 全局 token：跨文件复用值

```kotlin
// 页面内容横向边距（TodoScreen.kt:1868-1870）
Modifier.padding(
    bottom = bottomInset + ListBottomSlack,
    start = PageHorizontalSpacing,
    end = PageHorizontalSpacing,
)

// 浮层内容列顶层块节奏（RepeatSettingsSheet.kt:155）
Column(verticalArrangement = Arrangement.spacedBy(SheetSectionSpacingBetween))

// 行高下限（SheetInfoCard.kt:64）
Modifier.heightIn(min = SheetFieldHeight)
```

### 4.2 文件私有常量：单文件专用值

条件：仅本文件使用、出现两处以上、语义化命名、带 KDoc 说明场景与分工。

```kotlin
/** 收集箱视图的卡片间距：两列之间与同列上下卡之间都取 10dp（需求定值） */
private val InboxCardSpacing = 10.dp
```

**反例**：与全局 token 同值同义的镜像常量（如再写一个 `= 12.dp` 的页边距），改值时必然漏改。

### 4.3 行内字面量：单次微调

**允许**：

- 2–4dp 级视觉补偿（对齐、裁剪、进度条）；
- 一次性几何（`Spacer` 占位、单文件的确认框自有节奏，如 `ConfirmDialog.kt` 的 12/10/28/24/52）。

**禁止**：

- 写成全局节奏的字面量：页面边距 12、组间 18、组内卡距 10、行卡 16/14——这些一律走 token（过渡期例外见 §10.14）；
- 阶梯外的随意值。

### 6.2 字号 / 行高 / 字距 → 《字体使用规范》

`sp` 不是间距，一律走 `ClassppTextTokens` / `classppTextStyles`，本文不管。

### 6.3 颜色 → 《颜色使用规范》

分割线、描边、阴影的颜色取色规则见姊妹规范，本文只管 `thickness` 等尺寸。

### 6.4 动效 → `ui/motion`

按压缩放、弹簧参数、转场位移属于动效体系（`pressScale` / `pressFeedback`），不在本文阶梯内；`ai/AiChatOverlay.kt` 的跟底步长（8/24）同理。

## 7. 新增 / 修改间距的流程

1. **认场景**：先在第 5 节场景对照表里找到它属于哪个场景。
2. **查阶梯**：对照第 2 节选档；同场景已有 token 就直接复用，不新建近义 token。
3. **选表达方式**：跨文件 → `Spacing.kt` token；单文件两处以上 → 私有常量；单次微调 → 行内字面量（限 2–4dp 或一次性几何）。
4. **命名 + KDoc**：私有常量与 token 都要语义化命名，KDoc 说明「谁在用、与相邻值的分工」。
5. **确需新值/新 token**：先改 `Spacing.kt`（或在第 2 节阶梯登记），再同步本规范第 3 节与场景表；不要在调用处直接写值。
6. **验收**：跑第 9 节扫描命令，确认没有把全局节奏写成字面量、没有新增阶梯外值。

## 8. 禁止事项与代码审查清单

### 8.1 禁止写法

| 写法 | 问题 | 改成 |
|---|---|---|
