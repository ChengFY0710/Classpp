# Classpp 颜色使用规范

> **状态**：当前生效
> **基准**：`d79cc42`（2026-10-28）+ 第一批清理与 `onSurfaceVariant` 归一（未提交）+ 2026-11-09 深色档 `negative` → `#666666` / `switchDisabled` → `#1F1F1F`、滑杆未填充轨道取 `classppColors.onSurfaceCard` 并按 80% 不透明度叠底、开关未选中轨道取 `onSurfaceCard` 实色、滑杆默认值标记改黑色（浅 10% / 深 36%）+ 2026-11-10 日历待办小点改取 `onSurfaceCard`、选择方格禁用态改为 `onSurfaceCard` 底 + `secondaryText` 字
> **适用范围**：`app/src/main/java` 下全部 Jetpack Compose 取色，以及 `res` 的窗口背景与图标填充
> **唯一事实源**：`ui/theme/Color.kt`（全局色值定义）+ `ui/theme/ThemeAccent.kt`（主题色八档色板）+ `ui/theme/Theme.kt`（装配与访问入口）
> **姊妹规范**：`docs/字体使用规范.md`（token 不含颜色，其第 9 节的补色规则由本文承接）
> **自动守卫**：`app/src/test/java/com/fangyi/classpp/ui/theme/ColorUsageRulesTest.kt`

## 0. 快速规则

1. **业务代码不写裸色值。** 不写 `Color(0xFF…)`，不写 `#RRGGBB`。取色只有三个通道：`colorScheme` 槽位 → `ClassppColors` 扩展色 → 功能调色板（课程 18 色 / 标签 8 色）。
2. **文字补色口径固定。** 标题/正文用 `colorScheme.onSurface`，次级说明用 `classppColors.secondaryText`，强调/选中/链接用 `colorScheme.primary`；设置页 / 浮层 / 行卡 / 表单直接用 `MaterialTheme.classppTextStyles.*`（颜色随角色自带，见《字体使用规范》第 9 节）。
3. **危险与紧急只用一套色。** 删除、逾期、当天截止、Critical 旗标一律 `colorScheme.error`；紧急五档映射固定（见 4.3），截止时间配色与旗标共用同一套色。
4. **弱化与禁用是两个 token。** 「刻意弱化」（本周不上的课、禁用菜单行）用 `classppColors.negative`；开关不可点轨道用 `classppColors.switchDisabled`。语义不同，不混用。
5. **深浅色由主题装配，调用处不分支。** 禁止按 `isDarkTheme` 挑不同色值；它只允许既定的四类深浅分档封装（见 6.4）。
6. **恒白 / 恒黑只限例外场景。** 台历压图文字、开关/滑杆滑球、玻璃导航选中态、阴影基色、滑杆默认值标记（见 6.5 与第 11 节白名单）。
7. **渐变只允许同色透明度渐变。** 目前唯一用法是设置页信息头部卡图标（`iconColor` 默认 `colorScheme.primary`，45° 斜向 100% → 25% 同色）；不新增多色或装饰性渐变。**唯一例外**：AI 对话浮层底部「思考光场」（`ui/ai/AiThinkingAurora.kt`），四颗 `classppColors.aiAurora*` 光斑叠成极光场，仅限该组件，不得复制到其它背景。

## 1. 文件职责与取用顺序

| 文件 | 职责 | 什么时候用 |
|---|---|---|
| `ui/theme/Color.kt` | 63 个顶层 val（浅/深成对），全项目唯一全局色值定义点 | 业务代码**不直接引用**，经 Theme.kt 装配后取用 |
| `ui/theme/ThemeAccent.kt` | 主题色八档（蓝/厦大蓝/青/绿/紫/橙/粉/山大红）的文件私有浅/深色值与枚举绑定：主色、onPrimary、选中实色、scrim；页面背景由 `background()` 按 HSL 派生；默认蓝复用 Color.kt 常量 | 仅主题色选择器经 `ThemeAccent.primary(darkTheme)` 取色球色，其余场景读 `colorScheme` |
| `ui/theme/Theme.kt` | 装配 `colorScheme`（15 槽位）与 `ClassppColors`（15 token），提供 `MaterialTheme.classppColors` / `isDarkTheme` / `themeAccent` | 业务取色主入口 |
| `ui/theme/Type.kt` | `ClassppTextStyles` 7 个角色样式（颜色随角色自带） | 设置页、浮层、行卡、表单文字 |
| `ui/schedule/CourseCard.kt` | 课程 18 色 `CourseColor` 的浅/深映射（`barColorLight` / `barColorDark`） | 课表、日程任务条、选课色球、课程标签色 |
| `ui/note/NewTodoSheet.kt` | `NewTagColorPalette` 标签 8 色（深浅同值） | 待办标签选色 |
| `res/values*/colors.xml` | 冷启动窗口背景 | 仅 `themes.xml` 与 `values-night` 消费 |

取用顺序：

1. 有明确语义槽位 → `MaterialTheme.colorScheme.*`
2. 槽位之外的自定义语义（次级文字、弱化、禁用、磨砂、旗标橙黄绿…）→ `MaterialTheme.classppColors.*`
3. 课程配色 → `CourseColor.barColor(MaterialTheme.isDarkTheme)`；标签色 → `NewTagColorPalette`
4. 文字 → 优先 `MaterialTheme.classppTextStyles.*`；其他文字按快速规则 2 在调用处补色
5. **禁止**：直接 import `ui/theme` 顶层色值、业务侧写 `Color(0x…)`、按 `isDarkTheme` 手动挑色

## 2. `colorScheme` 槽位

`Theme.kt` 用 `lightColorScheme(...)` / `darkColorScheme(...)` 显式装配以下 16 个槽位。

| 槽位 | 浅色 | 深色 | 用途 | 引用 |
|---|---|---|---|---:|

| `onPrimary` | `#FFFFFF` | `#003062` | primary 底上的文字/图标 | 12 |
| `primaryContainer` | 蓝 12%（`0x1F006FEF`） | 蓝 27%（`0x45479CFF`） | 今天日期胶囊底、账户头像圆底 | 3 |
| `onPrimaryContainer` | 黑 10%（`0x1A000000`） | 灰蓝 20%（`0x339AA2AC`） | 日期带胶囊文字、浮层把手 | 2 |
| `inversePrimary` | 蓝 30%（`0x4D006FEF`） | 蓝 60%（`0x99479CFF`） | （存量 1 处，勿新增） | 1 |
| `background` | `#F2F4F6` | `#0F1114` | 页面底、底部渐隐遮罩终点（默认蓝；随主题色：H 取主色，S/L 取本行中性底） | 37 |
| `surface` | `#FFFFFF` | `#292D32` | 卡片、浮层底（浅色恒 `#FFFFFF`；深色随主题色：H 取主色，S/L 取 `#292D32`；除默认蓝/厦大蓝外 S 降至 6%） | 62 |
| `onSurface` | `#000000` | `#E4E7EA` | 主文字 | 70 |
| `onSurfaceVariant` | `#444746` | `#9BA2AB` | 已归一：业务零使用（守卫禁新增），槽位保留装配供 M3 组件内部消费 | 0 |
| `surfaceContainerHigh` | `#EAEDF1` | `#1E2227` | M3 对话框（AlertDialog/DatePicker）底，**不可省**——不装配会静默回退库默认淡紫灰 | 组件内部 |
| `outline` | `#DCE2E7` | `#2A2F36` | 课表网格线、时间轴线、分割线（默认蓝；其余档随主题色：H 取主色，S/L 取本行值） | 5 |
| `error` | `#F44336` | `#FF5449` | 删除滑动底、逾期/当天截止、Critical 旗标、危险菜单项 | 35 |
| `onError` | `#FFFFFF` | `#CC0C00` | error 底上的文字/图标（顶栏删除胶囊、删除确认胶囊、左滑删除图标）；玻璃模式下顶栏删除胶囊改用 `classppColors.onPrimaryGlass` | 11 |
| `errorContainer` | `#F9DEDC` | `#4A1C18` | 错误容器底 | 组件内部 |
| `onErrorContainer` | `#410E0B` | `#FFD9D4` | 错误容器内容 | 组件内部 |
| `scrim` | 蓝灰 20%（`0x332A333C`） | 黑 75%（`0xBF000000`） | 弹层遮罩、投影基色（深浅构成不同，系有意设计；默认蓝；随主题色，alpha 固定） | 6 |

引用数统计口径：`MaterialTheme.colorScheme.*` 前缀，基准 `d068c58`，合计 337 处；滑杆未填充轨道 1 处已迁至 `classppColors.onSurfaceCard`、选择方格禁用底 1 处已迁至 `classppColors.onSurfaceCard`，当前口径为 335 处。

> `primary` / `onPrimary` / `primaryContainer` / `inversePrimary` / `background` / `outline` / `scrim`
> 随主题色切换（`surface` 仅深色档跟随：H 取主色，S/L 取 `#292D32`；浅色恒 `#FFFFFF`；
> 除默认蓝/厦大蓝外，其余档深色 surface 的 S 降至 6%；`outline` 默认蓝保留原值）：
> 上表为默认蓝档；半透明槽位恒为 `primary.copy(alpha = 0x1F / 0x45 / 0x4D / 0x99)`，
> `background` 由 `ThemeAccent.background(dark)` 按 HSL 派生——H 取当前主色，S/L 固定取中性底
> （浅 `#F2F4F6`：18.18% / 95.69%；深 `#0F1114`：14.29% / 6.86%），不与中性底混色；
> `scrim` 的 alpha 固定不变（浅 20% / 深 75%），各档取值见附录 A.3。
> error、`onPrimaryContainer` 与 `surfaceContainerHigh` 不随主题色变化。

**未装配槽位警示**：`outlineVariant`（`PopupMenuCard` 分割线 1 处）、`secondary` / `tertiary` 全家（零使用，但停留 M3 紫色基线）。**先在 `Theme.kt` 装配再使用**，详见第 12 节。

> `secondaryText` 随主题色：由 `ThemeAccent.secondaryText(dark)` 按 HSL 派生——H 取当前主色，
> S/L 固定取默认灰（浅 `#ABAFB4`：5.66% / 68.82%；深 `#7E858D`：6.17% / 52.35%），默认蓝逐位一致。
> `secondaryGrey` 同规则派生（浅 `#60656C`：5.88% / 40%；深 `#C3C7CA`：6.19% / 77.84%），
> 默认蓝保留原值。
> `onSurfaceCard` 同规则派生（浅 `#DCE2E7`：18.64% / 88.43%；深 `#4D5157`：6.10% / 32.16%），
> 默认蓝保留原值。

## 4. 功能调色板

### 4.1 课程 18 色（`CourseColor`）

- 枚举定义在 `ui/schedule/ScheduleModels.kt`；颜色映射集中在 `ui/schedule/CourseCard.kt` 的 `barColorLight` / `barColorDark` 两张表。
- 深色版 = 浅色版明度、饱和度同比降至 75%（明度保底 0.44，色相不变），呈深卡上的低饱和同色系。
- **唯一取用方式**：`CourseColor.barColor(dark)`，`dark` 传 `MaterialTheme.isDarkTheme`。
- 消费方：课程卡竖条与时间文字（`CourseCard.kt`）、选课色球（`AddCoursePanel.kt:540`）、日程任务条（`DayTaskCard.kt` / `DayCourseAlert.kt` / `DayTimeline.kt`）、课程标签色（`NewTodoSheet.kt`，同名枚举经 `name` 直转）。
- 双表为手工维护：**改任何一色必须浅/深两表同步**。全部色值见附录 A.2。

### 4.2 标签 8 色（`NewTagColorPalette`）

定义在 `ui/note/NewTodoSheet.kt:87`，硬编码且**深浅主题同值**（有意为之，注释明示）：作标签胶囊底色时选中态白字可读、未选中 30% 透明底上文字也清晰。

珊瑚红 `#E5645C` · 暖橙 `#EF8A3C` · 芒果黄 `#E3B23E` · 草绿 `#66BB6A` · 湖青 `#26A69A` · 晴蓝 `#5C9CE6` · 薰紫 `#9575CD` · 桃粉 `#F06292`

### 4.3 紧急五档与截止配色

紧急旗标（`UrgentFlagCard.kt:42` 的 `TodoUrgency.flagColor()`）：

| 档位 | 颜色 |
|---|---|
| Critical（非常紧急） | `colorScheme.error` |
| High（很紧急） | `classppColors.urgentOrange` |
| Medium（紧急） | `classppColors.urgentYellow` |
| Low（不紧急） | `classppColors.urgentGreen` |
| None（无旗标） | `classppColors.secondaryText` |

截止时间配色（`TodoScreen.kt:1824` 的 `Todo.deadlineColor()`，与倒计时数字同一份天数、永远同步）：

| 距截止 | 颜色 |
|---|---|
| > 2 天（或无截止） | `colorScheme.primary` |
| 剩 2 天 | `classppColors.urgentYellow` |
| 剩 1 天 | `classppColors.urgentOrange` |
| 当天及已逾期 | `colorScheme.error` |

打卡模式卡片的「XX%」文字与卡底进度条不吃新色：两处都直接复用 NoteCard 已传入的 `deadlineColor`（上表同一份阶梯，无截止即 primary 蓝），与截止倒计时始终同色。

待办特殊分组页强调色（`TodoTopBar.kt`）：已完成 = `urgentGreen`、已逾期/回收站 = `error`、其余 = `primary`。

完成情况日历状态球（`TodoCompletionSheet` 经 `DayCalendar.dayStates`）：已完成 = `classppColors.urgentGreen` 球 + 白字、已逾期未完成 = `colorScheme.error` 球 + 白字、今天 = `colorScheme.primary` 球 + `onPrimary`；仅本月过去日期上状态色（前后月补位保持灰字 + `classppColors.onSurfaceCard` 小点）。

日历待办小点（`DayCalendar.markedDates`）：`classppColors.onSurfaceCard`（卡面细弱小点），位于日期圆球下方。

### 6.4 允许的变换

- `copy(alpha = …)`：透明度调整（磨砂 `hazeTint`、玻璃染色 `primary.copy(tintAlpha)`、遮罩渐变、滑杆未填充轨道 `classppColors.onSurfaceCard.copy(alpha = 0.8f)`）。**不允许**借 `copy` 换语义。
- `Brush.linearGradient`：仅允许同色透明度渐变（起点 `color` → `color.copy(alpha = 0.25f)`），当前唯一用法是设置页信息头部卡图标（`SettingsInfoHeaderCard.kt`）；调用点可换语义色，不得改成多色渐变。
- `Brush.radialGradient`：唯一例外是 AI 对话浮层底部光场（`AiThinkingAurora`），四颗 `classppColors.aiAurora*` 光斑 + 垂直 alpha 遮罩；仅限该组件，不得新增其它多色渐变。
- `isDarkTheme` 只允许六类既定场景，新增需同步本规范与守卫测试：
  1. 课程调色板参数：`CourseColor.barColor(MaterialTheme.isDarkTheme)`；
  2. 按压反馈明暗方向：`if (isDarkTheme) PressShade.Brighten else PressShade.Darken`（行卡五组件）；
  3. 标签文字压暗系数：`TagTextDimFactorLight/Dark`、`TaskTagTextDimFactorLight/Dark`（0.5f / 0.95f）；
  4. 台历日期视觉随深浅重算（`DayScreen.kt:270`）与标签色 `remember` key（`NewTodoSheet.kt:193`）；
  5. 主题色色球参数：`ThemeAccent.primary(MaterialTheme.isDarkTheme)`（个性化页选择器，按既定「局部变量」形态读取）。
  6. 滑杆默认值标记的黑色透明度系数：`MarkerAlphaLight = 0.1f` / `MarkerAlphaDark = 0.36f`（`ClassppSlider.kt`，按深浅选 Float 系数后 `Color.Black.copy(alpha = …)`；守卫 `isDarkThemeUsageIsBounded` 已加对应放行规则）。

## 7. XML 资源层（仅冷启动与图标）

- `res/values/colors.xml` 的 3 个定义**只服务窗口背景**：`background` / `background_light` / `background_dark`（三窗口主题 `Theme.Classpp` / `.Light` / `.Dark` 的 `android:windowBackground`，MainActivity 按持久化偏好 `setTheme`）。原 `background_blue` / `brand_blue` 死定义已删除（2026-10-28）。

- **规则**：XML 不新增颜色。新 UI 颜色一律走 Compose 主题；XML 只保留**默认蓝**的中性窗口底色。`MainActivity.onCreate` 按已存主题色读取 `ThemeAccent.background(dark)`，用 `ColorDrawable` 覆盖窗口背景，使首帧之前的窗口底色与 `colorScheme.background` 一致；新增主题色档位无需改 XML。
- 图标 drawable 全部 `#212121` 中性填充，运行时 `Icon(tint = …)` 上色；特例 `ic_calendar_liveupdates.xml` 填 `#479CFF`（= DarkPrimary）。新图标沿用「中性填充 + tint」。
- 例外：`SettingsInfoHeaderCard` 的图标不走 `Icon(tint)`，而是把 drawable 的 alpha 当遮罩、以 `BlendMode.SrcIn` 填入同色渐变；`fillColor` 同样不参与最终着色，新图标仍按中性填充导出即可。

## 8. 新增 / 修改颜色的流程

1. **认场景**：先在第 5 节「场景对照表」找到它属于哪个场景。
2. **选通道**：按第 1 节取用顺序——槽位 → `classppColors` → 功能调色板。
3. **复用优先**：不新建近义色。绿色有三种、蓝色有多源，先看第 12 节的分工再决定。
4. **确需新色**：在 `Color.kt` 新增**浅/深成对** val → 在 `Theme.kt` 装配（colorScheme 槽位或 `ClassppColors` 字段 + 语义注释）→ 同步本规范与 `ColorUsageRulesTest`。
   新增**主题色档位**走 `ThemeAccent.kt`：加文件私有浅/深成对 val（主色、onPrimary、选中实色、scrim）并在枚举绑定，同步附录 A.3；页面背景、深色 `surface`、`outline`、`secondaryText`、`secondaryGrey` 与 `onSurfaceCard` 由 HSL 规则自动派生，无需另配；默认蓝档必须复用 `Color.kt` 既有常量，其余五档不进入全局 token。
5. **不分深浅要写理由**：确有「深浅同值」理由的（如 `Correct`、标签 8 色），在注释里写明。
6. **验收**：跑第 10 节的编译、单测与扫描命令。
