# Classpp 颜色使用规范

> **状态**：当前生效
> **基准**：`d79cc42`（2026-10-28）+ 第一批清理与 `onSurfaceVariant` 归一（未提交）
> **适用范围**：`app/src/main/java` 下全部 Jetpack Compose 取色，以及 `res` 的窗口背景与图标填充
> **唯一事实源**：`ui/theme/Color.kt`（色值定义）+ `ui/theme/Theme.kt`（装配与访问入口）
> **姊妹规范**：`docs/字体使用规范.md`（token 不含颜色，其第 9 节的补色规则由本文承接）
> **自动守卫**：`app/src/test/java/com/fangyi/classpp/ui/theme/ColorUsageRulesTest.kt`

---

## 0. 快速规则

1. **业务代码不写裸色值。** 不写 `Color(0xFF…)`，不写 `#RRGGBB`。取色只有三个通道：`colorScheme` 槽位 → `ClassppColors` 扩展色 → 功能调色板（课程 18 色 / 标签 8 色）。
2. **文字补色口径固定。** 标题/正文用 `colorScheme.onSurface`，次级说明用 `classppColors.secondaryText`，强调/选中/链接用 `colorScheme.primary`；设置页 / 浮层 / 行卡 / 表单直接用 `MaterialTheme.classppTextStyles.*`（颜色随角色自带，见《字体使用规范》第 9 节）。
3. **危险与紧急只用一套色。** 删除、逾期、当天截止、Critical 旗标一律 `colorScheme.error`；紧急五档映射固定（见 4.3），截止时间配色与旗标共用同一套色。
4. **弱化与禁用是两个 token。** 「刻意弱化」（本周不上的课、禁用菜单行）用 `classppColors.negative`；开关不可点轨道用 `classppColors.switchDisabled`。语义不同，不混用。
5. **深浅色由主题装配，调用处不分支。** 禁止按 `isDarkTheme` 挑不同色值；它只允许既定的四类深浅分档封装（见 6.4）。
6. **恒白 / 恒黑只限例外场景。** 台历压图文字、开关/滑杆滑球、玻璃导航选中态、阴影基色（见 6.5 与第 11 节白名单）。

## 1. 文件职责与取用顺序

| 文件 | 职责 | 什么时候用 |
|---|---|---|
| `ui/theme/Color.kt` | 51 个顶层 val（浅/深成对），全项目唯一色值定义点 | 业务代码**不直接引用**，经 Theme.kt 装配后取用 |
| `ui/theme/Theme.kt` | 装配 `colorScheme`（15 槽位）与 `ClassppColors`（10 token），提供 `MaterialTheme.classppColors` / `isDarkTheme` | 业务取色主入口 |
| `ui/theme/Type.kt` | `ClassppTextStyles` 7 个角色样式（颜色随角色自带） | 设置页、浮层、行卡、表单文字 |
| `ui/schedule/CourseCard.kt` | 课程 18 色 `CourseColor` 的浅/深映射（`barColorLight` / `barColorDark`） | 课表、日程任务条、选课色球、课程标签色 |
| `ui/note/NewTodoSheet.kt` | `NewTagColorPalette` 标签 8 色（深浅同值） | 待办标签选色 |
| `res/values*/colors.xml` | 冷启动窗口背景 | 仅 `themes.xml` 与 `values-night` 消费 |

取用顺序：

1. 有明确语义槽位 → `MaterialTheme.colorScheme.*`
2. 槽位之外的自定义语义（次级文字、弱化、禁用、磨砂、旗标橙黄绿…）→ `MaterialTheme.classppColors.*`
3. 课程配色 → `CourseColor.barColor(MaterialTheme.isDarkTheme)`；标签色 → `NewTagColorPalette`
4. 文字 → 优先 `MaterialTheme.classppTextStyles.*`；其他文字按快速规则 2 在调用处补色
5. **禁止**：直接 import `ui/theme` 顶层色值、业务侧写 `Color(0x…)`、按 `isDarkTheme` 手动挑色

## 4. 功能调色板

### 4.1 课程 18 色（`CourseColor`）

- 枚举定义在 `ui/schedule/ScheduleModels.kt`；颜色映射集中在 `ui/schedule/CourseCard.kt` 的 `barColorLight` / `barColorDark` 两张表。
- 深色版 = 浅色版明度、饱和度同比降至 75%（明度保底 0.44，色相不变），呈深卡上的低饱和同色系。
- **唯一取用方式**：`CourseColor.barColor(dark)`，`dark` 传 `MaterialTheme.isDarkTheme`。
- 消费方：课程卡竖条与时间文字（`CourseCard.kt`）、选课色球（`AddCoursePanel.kt:540`）、日程任务条（`DayTaskCard.kt` / `DayCourseAlert.kt` / `DayTimeline.kt`）、课程标签色（`NewTodoSheet.kt`，同名枚举经 `name` 直转）。
- 双表为手工维护：**改任何一色必须浅/深两表同步**。全部色值见附录 A.2。

### 4.2 标签 8 色（`NewTagColorPalette`）

定义在 `ui/note/NewTodoSheet.kt:87`，硬编码且**深浅主题同值**（有意为之，注释明示）：作标签胶囊底色时选中态白字可读、未选中 30% 透明底上文字也清晰。

珊瑚红 `#E5645C` · 暖橙 `#EF8A3C` · 芒果黄 `#E3B23E` · 草绿 `#66BB6A` · 湖青 `#26A69A` · 晴蓝 `#5C9CE6` · 薰紫 `#9575CD` · 桃粉 `#F06292`

### 4.3 紧急五档与截止配色

紧急旗标（`UrgentFlagCard.kt:42` 的 `TodoUrgency.flagColor()`）：

| 档位 | 颜色 |
|---|---|
| Critical（非常紧急） | `colorScheme.error` |
| High（很紧急） | `classppColors.urgentOrange` |
| Medium（紧急） | `classppColors.urgentYellow` |
| Low（不紧急） | `classppColors.urgentGreen` |
| None（无旗标） | `classppColors.secondaryText` |

截止时间配色（`TodoScreen.kt:1824` 的 `Todo.deadlineColor()`，与倒计时数字同一份天数、永远同步）：

| 距截止 | 颜色 |
|---|---|
| > 2 天（或无截止） | `colorScheme.primary` |
| 剩 2 天 | `classppColors.urgentYellow` |
| 剩 1 天 | `classppColors.urgentOrange` |
| 当天及已逾期 | `colorScheme.error` |

待办特殊分组页强调色（`TodoTopBar.kt`）：已完成 = `urgentGreen`、已逾期/回收站 = `error`、其余 = `primary`。

完成情况日历状态球（`TodoCompletionSheet` 经 `DayCalendar.dayStates`）：已完成 = `classppColors.urgentGreen` 球 + 白字、已逾期未完成 = `colorScheme.error` 球 + 白字、今天 = `colorScheme.primary` 球 + `onPrimary`；仅本月过去日期上状态色（前后月补位保持灰字 + Primary 小点）。

## 6. 取用方式与代码示例

### 6.1 语义槽位：`colorScheme`

```kotlin
Text(
    text = course.name,
    style = ClassppTextTokens.compactCardTitle,
    color = MaterialTheme.colorScheme.onSurface,
)
```

### 6.2 扩展语义：`classppColors`

```kotlin
Text(
    text = note,
    style = ClassppTextTokens.metaText,
    color = MaterialTheme.classppColors.secondaryText,
)
```

### 6.3 角色样式自带颜色：`classppTextStyles`

设置页 / 浮层 / 行卡 / 表单优先用，不必再补色：

```kotlin
Text(text = label, style = MaterialTheme.classppTextStyles.fieldLabel)   // onSurface
Text(text = value, style = MaterialTheme.classppTextStyles.fieldValue)   // primary
```

### 6.4 允许的变换

- `copy(alpha = …)`：透明度调整（磨砂 `hazeTint`、玻璃染色 `primary.copy(tintAlpha)`、遮罩渐变）。**不允许**借 `copy` 换语义。
- `isDarkTheme` 只允许四类既定场景，新增需同步本规范与守卫测试：
  1. 课程调色板参数：`CourseColor.barColor(MaterialTheme.isDarkTheme)`；
  2. 按压反馈明暗方向：`if (isDarkTheme) PressShade.Brighten else PressShade.Darken`（行卡五组件）；
  3. 标签文字压暗系数：`TagTextDimFactorLight/Dark`、`TaskTagTextDimFactorLight/Dark`（0.5f / 0.95f）；
  4. 台历日期视觉随深浅重算（`DayScreen.kt:270`）与标签色 `remember` key（`NewTodoSheet.kt:193`）。

### 6.5 恒白 / 恒黑例外

| 场景 | 写法 | 位置 |
|---|---|---|
| 台历压图文字/图标（白字压照片，不分深浅） | `Color.White` | `DayScreen.kt:1176/1183/1268/1280/1286` |
| 台历图片压暗 | `Color.Black.copy(alpha = 0.24f)` | `DayScreen.kt` |
| 开关 / 滑杆滑球 | `Color.White` | `ClassppSwitch.kt:93`、`ClassppSlider.kt` |
| 玻璃导航选中态内容 | `Color.White` | `BottomNavBar.kt:161` |
| 完成情况日历状态球文字（绿/红球上恒白） | `Color.White` | `DayCalendar.kt`（`TodoCompletionSheet` 使用） |
| 组件投影基色 | `Color.Black.copy(alpha = 0.15–0.3f)` | `OverlaySheet`、`PopupMenuCard`、`TodoTopBar`、`PressScale` 等 |

## 7. XML 资源层（仅冷启动与图标）

- `res/values/colors.xml` 的 3 个定义**只服务窗口背景**：`background` / `background_light` / `background_dark`（三窗口主题 `Theme.Classpp` / `.Light` / `.Dark` 的 `android:windowBackground`，MainActivity 按持久化偏好 `setTheme`）。原 `background_blue` / `brand_blue` 死定义已删除（2026-10-28）。
- `res/values-night/colors.xml` 仅 `background = #0F1114`：系统深色下冷启动首帧即深底，不闪白。
- **规则**：XML 不新增颜色。新 UI 颜色一律走 Compose 主题；窗口背景如需调整，同步改 `values` / `values-night` / `themes.xml` 三处并保持与 `colorScheme.background` 一致。
- 图标 drawable 全部 `#212121` 中性填充，运行时 `Icon(tint = …)` 上色；特例 `ic_calendar_liveupdates.xml` 填 `#479CFF`（= DarkPrimary）。新图标沿用「中性填充 + tint」。

## 8. 新增 / 修改颜色的流程

1. **认场景**：先在第 5 节「场景对照表」找到它属于哪个场景。
2. **选通道**：按第 1 节取用顺序——槽位 → `classppColors` → 功能调色板。
3. **复用优先**：不新建近义色。绿色有三种、蓝色有多源，先看第 12 节的分工再决定。
4. **确需新色**：在 `Color.kt` 新增**浅/深成对** val → 在 `Theme.kt` 装配（colorScheme 槽位或 `ClassppColors` 字段 + 语义注释）→ 同步本规范与 `ColorUsageRulesTest`。
5. **不分深浅要写理由**：确有「深浅同值」理由的（如 `Correct`、标签 8 色），在注释里写明。
6. **验收**：跑第 10 节的编译、单测与扫描命令。

## 9. 禁止事项与代码审查清单

### 9.1 禁止写法

| 写法 | 问题 | 改成 |
|---|---|---|
| `Color(0xFF…)`（业务代码） | 绕过主题，深浅失配 | 三个取用通道之一 |
| `import com.fangyi.classpp.ui.theme.Error` / `Correct` 等 | 直连顶层 val，深色不切换 | `colorScheme.error` 等（学期标色两处挂账待迁移） |
| `if (isDarkTheme) Color(…) else Color(…)` | 手动挑色，主题形同虚设 | 主题装配；确属深浅分档封装见 6.4 |
| `Color.White` / `Color.Black` 作常规前景/背景 | 例外之外（见 6.5） | `onSurface` / `surface` / 语义色 |
| 使用未装配槽位（`onError`、`outlineVariant`…） | 静默回退 M3 基线（紫灰系） | 先在 `Theme.kt` 装配再使用 |
| 同一语义多处取色（如「错误红」两个来源） | 深色下出现两个色值 | 统一走 `colorScheme.error` |

### 9.2 审查清单

- [ ] 没有新增业务侧 `Color(0x…)`
- [ ] 没有 import `ui/theme` 顶层色值
- [ ] 没有新增 `isDarkTheme` 分支挑色（四类既定场景除外）
- [ ] 恒白/恒黑只出现在 6.5 例外场景
- [ ] 新色浅/深成对，且已在 `Theme.kt` 装配
- [ ] 未触碰未装配槽位
- [ ] `ColorUsageRulesTest` 通过
